Open **File → Settings**, the settings button in the page list, or the one on the start screen. Changes save automatically after a short delay; choose **Back to editor** to return.

## Appearance

Choose **Light**, **Dark**, or **System**, and the interface language. These settings do not change page rendering or the translation target language.

## Pipeline

Choose the detection, OCR, and inpainting models. Detection has text, SFX, bubble, and panel thresholds; inpainting has the prompt the generative models follow. See [vision and inpainting models](/models/vision).

## Providers

Add API keys, sign in to subscriptions, and set base URLs for the connections listed in [translation providers](/models/providers). Keys and sign-ins are stored encrypted on this device; base URLs are saved in `config.toml`.

## Translation

Choose the translation model, **Vision**, **Reasoning**, the target language, and the system prompt. The processing selector also sets the model and target language. See [translation settings](/models/translation).

## Typesetting

Set the ordered default font families, CCWildWords and then Adobe 黑体 Std unless you change them. Koharu uses them for a text with no font of its own and when a font cannot supply a glyph, then falls back to system fonts. Individual text layers still own their typography.

## Shortcuts

Assign one character to Select, Text, Brush, Eraser, Color picker, Remove, Pan, and Fit Window. Custom bindings apply to the running session only; they are not saved and reset to the defaults when Koharu restarts.

<Note>
  Settings live in `~/.koharu/config.toml`, a table per component: `[pipeline]` (including
  `[pipeline.translator]`), `[providers]`, `[renderer]` for typesetting, and `[agent]`. The file can
  be edited by hand for options the app has no screen for; a value of the wrong type is an error,
  never a default. Keep credentials out of it and use **Settings → Providers** instead.
</Note>

See [data locations](/reference/data) for project and download storage.
