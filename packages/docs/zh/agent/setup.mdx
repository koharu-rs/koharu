title: '设置 Koharu Agent'

Koharu Agent 是编辑器内置的项目助手。只要模型能调用工具，翻译可选的任何模型都能用来运行它：托管模型、ChatGPT 等订阅，或 Koharu 的通用本地模型。

<Steps>
  <Step title='连接服务商'>
    在**设置 → 提供商**中填写 API
    密钥或登录；使用本地模型时可跳过此步。参见[翻译服务商](/zh/models/providers)。
  </Step>
  <Step title='打开智能体面板'>打开项目，在右侧选择**图层**和**故事**旁边的**智能体**标签页。</Step>
  <Step title='选择模型'>
    在消息框下方选择模型和推理等级。**提供商默认值**使用模型自身的等级，**关闭**会在模型支持时不进行推理。更多推理有助于处理含糊的编辑，但耗时更长。旁边的**新对话**会让对话重新开始。
  </Step>
</Steps>

## 共享哪些上下文

每次请求都从打开项目的概要开始：页面及其图层。只有当智能体调用页面查看工具时，才会渲染并附上页面图像；它不会自动附上每一页。托管模型的服务商会收到智能体发送的内容。

<Note>
  智能体与翻译共享服务商连接，但不共享模型：智能体的模型和推理等级与翻译分开，保存在
  `~/.koharu/config.toml` 的 `[agent]` 部分。智能体的系统提示词由 Koharu 固定，无法修改。
</Note>

## 通过 MCP 连接其他智能体

Koharu 运行期间，会通过 MCP 的 Streamable HTTP 传输向其他程序中的智能体提供同一套工具。请把以下地址添加到同一台机器上的 MCP 客户端：

```text
http://127.0.0.1:7878/mcp
```

该地址每次启动都相同；如果 Koharu 启动时 7878 端口已被其他程序占用，服务器就不会运行。服务器作用于当前打开的项目，只接受本机连接，并拒绝来自网页的请求。
