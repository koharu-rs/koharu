为当前打开的项目指定具体目标，说明页面范围、期望变化和必须保持不变的部分。

## 编写明确的请求

<Tabs>
  <Tab title="文字审阅">
    > 检查第 3–5 页，修正明显的 OCR 错误，翻译成自然英语并保留敬称。不要改变排字。
  </Tab>
  <Tab title="视觉审阅">
    > 检查第 8 页的文字是否溢出气泡，只调整字号和换行。
  </Tab>
</Tabs>

许多文字编辑只需语义检查。涉及外观时，再要求视觉检查。

## 可用操作

Agent 可以读取当前语义状态、渲染指定页面、重命名/排序/删除页面、添加段落框、编辑原文和译文、修改排字和几何、调整可见性和不透明度、移动或删除元素，以及按项目、页面或文本元素范围运行配置好的流程。

<Note>项目工具不能导入源文件、导出文件、管理服务凭据，或操作当前项目之外的内容。</Note>

## 编辑、取消与历史

Agent 使用与桌面 UI 相同的项目操作。成功编辑会更新场景、渲染器、修订号与撤销历史。

流水线逐步提交已完成阶段。取消 Agent 请求也会请求协作停止由其启动的处理任务。同一时间只能运行一个 Agent 请求。

<Steps>
  <Step title='检查变化页面'>查看原文、译文与画布。</Step>
  <Step title='检查布局'>按正常阅读大小确认几何和排字。</Step>
  <Step title='保留或撤销'>撤销不需要的改动，完成自己的检查后再导出。</Step>
</Steps>
