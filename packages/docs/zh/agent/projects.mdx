在当前打开的项目范围内给智能体一个具体目标，说明页面、想要的修改，以及不应改动的内容。

## 编写明确的请求

<Tabs>
  <Tab title="文字审阅">
    > 检查第 3–5 页，修正明显的 OCR 错误，翻译成自然英语并保留敬称。不要改变排字。
  </Tab>
  <Tab title="视觉审阅">
    > 检查第 8 页的文字是否溢出气泡，只调整字号和换行。
  </Tab>
</Tabs>

许多文字编辑只需读取项目的图层即可完成。涉及外观时，再要求视觉检查。

## 可用工具

| 工具          | 作用                                                     |
| ------------- | -------------------------------------------------------- |
| `get_project` | 按顺序列出页面                                           |
| `get_page`    | 按阅读顺序读取页面的分格、对白框和文本块，包括原文和译文 |
| `get_layer`   | 读取一个图层及其内部全部内容                             |
| `edit`        | 把对图层和页面的修改作为一个撤销步骤应用                 |
| `run`         | 对项目、部分页面、部分文本块或涂抹区域启动处理任务       |
| `wait`        | 最多等待 30 秒让任务结束，并返回目前的进展               |
| `stop`        | 停止所有处理任务                                         |
| `view_page`   | 以编辑器的绘制方式渲染页面                               |

<Note>这些工具不会导入或导出文件、管理服务商凭据，也不会操作当前项目以外的内容。</Note>

## 编辑、取消与历史

智能体的修改使用与编辑器相同的编辑，因此会实时重绘画布，每次修改都是一个撤销步骤。智能体启动的处理任务和其他任务一样显示在活动中心。

同一时间只运行一个请求。**取消**会停止智能体，正在应用的编辑会完整执行完。智能体启动的处理任务会继续运行，请在活动中心停止它。对话会跨请求延续，在更换智能体模型或关闭项目时结束。

<Steps>
  <Step title='检查修改的页面'>检查原文、译文和画布。</Step>
  <Step title='检查版式'>以正常阅读尺寸确认位置与排版。</Step>
  <Step title='保留或撤销'>撤销不需要的修改，审阅后再导出。</Step>
</Steps>
