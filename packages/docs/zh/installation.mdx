<Steps>
  <Step title="选择发行版">
    打开[最新 GitHub 发行版](https://github.com/koharu-rs/koharu/releases/latest)，选择适合你的操作系统和处理器的软件包。

    <Tabs>
      <Tab title="Windows">
        运行发行版中的 Windows 安装程序（`-setup.exe` 或 `.msi`），或使用 WinGet 安装：

        ```powershell
        winget install koharu
        ```
      </Tab>
      <Tab title="macOS">
        选择 Apple 芯片版本并将 Koharu 放入“应用程序”文件夹，或使用 Homebrew 安装：

        ```bash
        brew install --cask koharu
        ```
      </Tab>
      <Tab title="Linux">
        按处理器（x86-64 或 ARM64）选择 `.deb` 或 `.rpm` 软件包，并安装软件包管理器提示缺少的桌面库依赖。其他发行版请使用 `.AppImage`，它需要系统已安装 GTK 4。
      </Tab>
    </Tabs>

  </Step>
  <Step title="检查 GPU">
    Koharu 在 GPU 上运行模型，也用 GPU 绘制页面。首次运行前请查看[硬件与运行时](/zh/hardware)。
  </Step>
  <Step title="等待首次下载">
    首次运行模型时，Koharu 会下载适用于你的 GPU 的原生运行时软件包以及该模型的权重。下载完成前请保持应用打开，活动中心会显示进度。

    运行时软件包来自 GitHub 发行版附件，CUDA 来自 PyPI，ROCm 来自 AMD 的仓库；模型权重和字体来自 Hugging Face。

  </Step>
  <Step title="创建第一个项目">
    准备一张清晰的漫画页面，并按照[快速开始](/zh/quickstart)操作。
  </Step>
</Steps>

## 安装更新

发行版会在启动时检查一次签名的 GitHub 发行版更新源，不提供手动检查更新。出现更新时，选择**更新**并等待下载完成，Koharu 会安装更新并重新启动。选择**稍后**则在下次启动前继续使用当前版本。

<Tip>
  翻译工作请使用发行版。需要修改 Koharu 代码时，请查看[开发环境设置](/zh/development/setup)。
</Tip>
