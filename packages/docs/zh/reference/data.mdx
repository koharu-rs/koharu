## 支持的格式

| 用途     | 格式                                     |
| -------- | ---------------------------------------- |
| 导入     | PNG、JPEG、WebP、ZIP、CBZ、RAR、CBR、PDF |
| 拼合导出 | PNG，或由 PNG 页面组成的 CBZ             |
| 分层交换 | PSD                                      |
| 工作项目 | 一个 `.khr` 文件                         |

## 项目数据

每个项目都是项目文件夹中的一个 `.khr` 文件。项目文件夹在 Windows 上是 Koharu 安装文件夹中的 `projects`，在 macOS 上是 `~/Library/Application Support/Koharu/projects`，在 Linux 上是 `~/.local/share/Koharu/projects`。该文件是一个 SQLite 数据库，保存导入的图像、生成的图稿、栅格编辑和文字。项目打开期间，Koharu 会锁定该文件，并可能在旁边保留一个 `-wal` 文件。

<Warning>项目打开时不要修改或复制其文件。从开始界面删除项目会永久删除其文件。</Warning>

## 设置与凭据

设置保存在 `~/.koharu/config.toml` 中，每个组件一张表：`[pipeline]`、`[providers]`、`[renderer]` 和 `[agent]`。保持默认值的设置不会写入文件，因此默认值日后改变时会自动生效。不是有效 TOML 的文件或类型错误的值会报错，而不会悄悄改用默认值；请修正文件或使用设置界面。

API 密钥和登录信息加密保存在 `~/.koharu/secrets.age` 中。Koharu 在操作系统凭据存储中只保存其密钥；Linux 上需要 GNOME Keyring、KWallet 或 KeePassXC 等 Secret Service。密钥丢失后该文件将无法再读取并会被删除，你需要重新登录。项目备份不包含任何密钥或登录信息。

## 运行时与模型存储

运行时软件包和模型文件在 Windows 上保存在 Koharu 安装文件夹中的 `store` 文件夹，在 macOS 和 Linux 上保存在系统缓存文件夹中的 `koharu/store`。这些数据可以重新获取：在 Koharu 关闭时删除，所需文件会重新下载。

Koharu 可能仍加载着其中的库时，不要删除存储目录。

## 日志

Koharu 会把 INFO 及以上级别的消息写入日志文件，位置在 Windows 上为 `%LOCALAPPDATA%\Koharu\logs`，macOS 上为 `~/Library/Logs/Koharu`，Linux 上为 `~/.local/share/Koharu/logs`。如需更详细的日志，请参见[故障排除](/zh/reference/troubleshooting)。

## 安全备份

<Steps>
  <Step title='关闭项目'>复制文件前先完成当前工作。</Step>
  <Step title='复制项目文件'>复制 `.khr` 文件。PSD 或 CBZ 导出不是项目备份。</Step>
  <Step title='单独保存设置'>
    需要时复制 `config.toml`，并在恢复后的设备上通过 Koharu 重新连接服务商。
  </Step>
</Steps>
