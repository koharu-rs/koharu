工具和编辑快捷键在项目打开、且输入框、文本区域或可编辑文本区域未获得焦点时生效。

## 工具

| 工具     | 按键 |
| -------- | ---- |
| 选择     | `V`  |
| 直接选择 | `A`  |
| 矩形选框 | `M`  |
| 套索     | `L`  |
| 文本     | `T`  |
| 绘画     | `B`  |
| 橡皮擦   | `E`  |
| 取色器   | `I`  |
| 移除     | `J`  |
| 平移     | `H`  |

每个按键都与 Photoshop 中同一工具的按键相同。

## 导航

| 操作         | 手势                                      |
| ------------ | ----------------------------------------- |
| 临时平移     | 按住 `Space` 或鼠标中键拖动               |
| 平移         | 滚动；`Shift` + 滚动可水平平移            |
| 围绕指针缩放 | `Ctrl` 或 `Command` + 滚动，或双指捏合    |
| 调整画笔大小 | 在绘画、橡皮擦或移除工具下按 `Alt` + 滚动 |
| 清除选择     | `Escape`                                  |
| 适应当前页面 | `Ctrl+0` 或 `Command+0`                   |

松开 `Space` 后会回到原来使用的工具。

## 编辑

| 操作                                 | Windows / Linux         | macOS                   |
| ------------------------------------ | ----------------------- | ----------------------- |
| 撤销                                 | `Ctrl+Z`                | `Command+Z`             |
| 重做                                 | `Ctrl+Shift+Z`          | `Command+Shift+Z`       |
| 选择页面上的所有图层                 | `Ctrl+A`                | `Command+A`             |
| 取消矩形选框或套索的选区             | `Ctrl+D`                | `Command+D`             |
| 删除所选图层，或用直接选择选中的锚点 | `Delete` 或 `Backspace` | `Delete` 或 `Backspace` |
| 提交在画布上输入的文字               | `Ctrl+Enter`            | `Command+Enter`         |

快捷键只影响桌面界面，不影响导出的页面。
