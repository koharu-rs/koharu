---
title: '键盘快捷键'
description: '默认工具键、导航手势、选择和撤销命令。'
icon: 'keyboard'
---

项目打开且输入框、文本区域或可编辑文字区域未获得焦点时，工具与编辑快捷键生效。

## 工具

| 工具     | 按键 |
| -------- | ---- |
| 选择     | `V`  |
| 文本     | `T`  |
| 画笔     | `B`  |
| 橡皮擦   | `E`  |
| 取色器   | `I`  |
| 移除     | `J`  |
| 平移     | `H`  |
| 适应窗口 | `0`  |

在**设置 → 快捷键**中修改工具键。

## 导航

| 操作               | 手势                                  |
| ------------------ | ------------------------------------- |
| 临时平移           | 按住 `Space` 或鼠标中键并拖动         |
| 平移               | 滚动；`Shift` + 滚动可水平平移        |
| 在指针位置缩放     | `Ctrl` + 滚动                         |
| 调整画笔直径       | 使用画笔、橡皮擦或移除时 `Alt` + 滚动 |
| 取消手势并清空选择 | `Escape`                              |
| 适应当前页面       | 默认为 `0`                            |

按住 `Space` 期间当前工具不会改变。切离 Koharu 会取消未完成的画布手势。

## 编辑

| 操作                   | Windows / Linux         | macOS                   |
| ---------------------- | ----------------------- | ----------------------- |
| 撤销                   | `Ctrl+Z`                | `Command+Z`             |
| 重做                   | `Ctrl+Shift+Z`          | `Command+Shift+Z`       |
| 选择页面所有可编辑图层 | `Ctrl+A`                | `Command+A`             |
| 删除选中图层           | `Delete` 或 `Backspace` | `Delete` 或 `Backspace` |

<Tip>
  为各工具分配不同字符。发生冲突时，先检查适应窗口键，然后工具栏顺序中第一个匹配的工具优先。自定义按键会在
  Koharu 重启后重置。
</Tip>

快捷键仅影响桌面操作，不影响导出页面。
