一个项目是一个按顺序保存页面的 `.khr` 文件。每个页面由扫描图和一棵图层树组成。普通图层参照 Photoshop，漫画页面的组成部分参照 CLIP STUDIO PAINT 的分格和对白框。

## 页面的图层

检测按阅读顺序建立这棵树，因此页面从头到尾读起来是这样的：

<Tree>
  <Tree.Folder name='页面：扫描图作为背景' defaultOpen>
    <Tree.Folder name='分格' defaultOpen>
      <Tree.Folder name='对白框' defaultOpen>
        <Tree.File name='文本块' />
        <Tree.File name='文本块' />
      </Tree.Folder>
      <Tree.File name='文本块：拟声词，在分格中、对白框外' />
      <Tree.File name='文本块：旁白，在分格中、对白框外' />
    </Tree.Folder>
    <Tree.Folder name='分格'>
      <Tree.Folder name='对白框'>
        <Tree.File name='文本块' />
      </Tree.Folder>
    </Tree.Folder>
    <Tree.File name='文本块：不属于任何分格' />
    <Tree.File name='栅格：你自己的绘画' />
  </Tree.Folder>
</Tree>

| 图层     | 说明                                                                                                     |
| -------- | -------------------------------------------------------------------------------------------------------- |
| 背景     | 导入的扫描图，逐字节原样保存，绘制在最底层。任何东西都不会画在它上面，因此隐藏或删除上层内容就能看到原图 |
| 分格     | 分格的轮廓，包含在其中阅读的对白框和文字。它不裁切任何内容，因此跨越边线的对白框仍留在它所属阅读的分格中 |
| 对白框   | 对白框的轮廓，包含其中的文字。线条和填充本就是扫描图的一部分，因此轮廓本身不会被绘制                     |
| 文本块   | 页面上的一段文字，位于对白框中，或独立位于分格或页面上，见下文                                           |
| 普通类型 | 组、图像、栅格、形状、文本和蒙版，与 Photoshop 一样有可见性、锁定、不透明度和混合模式                    |

树的顺序就是阅读顺序。**故事**按这个顺序列出文字；**图层**与 Photoshop 的图层面板一样从最上层开始列出，因此最后阅读的文字位于最上面一行。在**图层**中拖动行，阅读顺序也会随之移动。

## 文本块

文本块把一段文字的四个部分放在一起，因此修正其中一个时无需重建其他部分。

| 部分 | 由谁写入                 | 是否绘制                             |
| ---- | ------------------------ | ------------------------------------ |
| 原文 | 检测的框，OCR 的文字     | 不绘制：它是模型读取、你来修正的内容 |
| 译文 | 翻译，或你的输入         | 绘制：在框中，位于清理之上           |
| 蒙版 | 检测，或你的绘画         | 不绘制：它决定清理显示的范围         |
| 清理 | 修补、**移除**、你的绘画 | 只在蒙版内绘制，位于译文之下         |

清理的工作方式就像 Photoshop 中带图层蒙版的填充图层：涂抹蒙版会立即显示更多或更少的清理，无需重新运行。因此各部分的表现如下：

- 删除文本块会一并删除它的清理，原来的文字会重新显示。
- 没有译文的文本块仍会显示清理，因此该区域会为新的文字保持干净。
- 每段文字在自己的框中有自己的译文。文字不会从一个框流入另一个框。

**文本**图层是你自己添加的文字，没有原文、蒙版和清理。

## 每次更改都是一次编辑

编辑器、流水线任务和 Agent 都通过同样的编辑来更改项目。一次编辑要么整体生效，要么完全不生效，每次编辑都是一个撤销步骤；什么也没改变的编辑不会添加步骤。

无论是模型还是你，最后写入的值生效，撤销是回退的方法。唯一的保护是锁定：任何流水线阶段都不会写入锁定的图层。

**视图 → 历史记录**在项目打开时的状态之后列出各个步骤，并且像 Photoshop 的历史记录面板一样，可以一步跳到任意步骤。它保留最近 20 个步骤（Photoshop 的默认值），项目关闭时清空，就像关闭 Photoshop 文档会清空其状态一样。

## 项目如何保存

- **一个文件。** 项目是扩展名为 `.khr` 的 SQLite 数据库，导入的图像也在其中，就像 CLIP STUDIO PAINT 的作品是一个文件。移动或删除原始文件不会影响项目。
- **无需保存。** 每次编辑在生效时即写入，因此项目不存在未保存的更改。
- **图块。** 栅格像素按 64 × 64 的图块分别压缩保存，只保存含有像素的图块。清理只保存它覆盖的区域。
- **一个窗口。** 打开的项目会被锁定，因此在另一个窗口或另一个 Koharu 中会显示为正在使用。
- **打不开就不打开。** 损坏的文件，或项目格式已改变的较新 Koharu 写入的文件，不会被打开，文件保持原样。
