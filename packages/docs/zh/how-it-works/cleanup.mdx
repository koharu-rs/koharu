清理，也就是**修补**阶段，会从扫描图上去除每段文字。结果写入文本块的清理中，只在文本块的蒙版内、译文之下显示。扫描图本身不会改变。

## 先填充，再用模型

大多数文字位于白纸或平滑的渐变上，用填充就能准确、立即地还原。在这些地方使用模型可能会增加纹理或色偏，因此 Koharu 只在需要时才使用模型。

Koharu 为每段文字读取蒙版外侧、对白框或分格内侧的一圈未被蒙版覆盖的像素，用第一个能还原这圈像素的层级来填充蒙版：

| 层级     | 条件                                                                               | 填充方式                          |
| -------- | ---------------------------------------------------------------------------------- | --------------------------------- |
| 单一颜色 | 这圈像素都在其中位数的 16 级以内，或平均同样接近且没有偏离很远的像素               | 中位数颜色                        |
| 平滑背景 | 减去拟合到这圈像素的渐变后满足同样条件                                             | 移植自 OpenCV 的 Telea 快速行进法 |
| 模型     | 其他情况：跨越对白框线条的文字、紧挨着的线条或画面、网点，或小到无法判断的一圈像素 | 修补模型                          |

周围不是单一颜色的文字，会按蒙版中各个分离的部分重新判断，因为检测可能把另一种纸面上、或对白框线条上的碎片也纳入蒙版。只有碎片所在纸面无法覆盖的部分（例如对白框轮廓之外的部分）才交给模型。

## 模型如何重绘

模型按页面原本的比例在窗口中工作。每个窗口完整包含一段文字及其周围 256 像素的上下文，只要合并后不超过约一百万像素，就与重叠的窗口合并，并且不会跨越两个分格。把整页缩小以适应模型会留下文字，把大窗口同样缩小会留下字形状的痕迹；按页面原本的比例，这两种情况都不会发生。

每段文字只在一个窗口中重绘，而且模型看到的是窗口内所有文字都被蒙版覆盖的样子，而不只是它在该窗口中重绘的那些。

## 移除与创成式填充

一次**移除**笔画本身就是一个任务：用**设置 → 流水线**中的修补模型对涂抹区域进行修补。整个区域都交给模型，不经过填充层级。它读取的是当前绘制出的页面，包括之前的清理、绘画和填充，但不含文字，就像 Photoshop 的移除工具对所有图层取样。在结果上再涂一笔会以它为基础，译文也不会被烘焙进填充。

结果会画在**图层**中选中的栅格图层或清理上，选中的清理的蒙版会在涂抹处打开。没有选中任何内容时，结果会画在一个限定于该区域的新栅格图层上，并保持选中以便后续笔画。

**创成式填充**在用**矩形选框**或**套索**标出的区域中，绘制提示词要求的内容。它有自己的模型（未选择其他模型时为 FLUX.3 Klein），并像 Photoshop 的创成式填充一样记住所选模型供下次使用。设置中未使用的填充模型会在最后一次填充后保持加载五分钟，因此再次填充时不必重新加载。

## 清理出问题时

| 看到的情况           | 处理方法                                               |
| -------------------- | ------------------------------------------------------ |
| 残留字形碎片         | 用**移除**涂抹，或从**故事**中该文字的菜单运行**修补** |
| 清理盖住了线稿或边线 | 在**图层**中选中文本块的蒙版并擦除，无需重新运行       |
| 好的结果被替换了     | 重新运行会替换清理：先撤销，再锁定要保留的文字         |
