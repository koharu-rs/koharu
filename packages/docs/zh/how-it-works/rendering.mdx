Koharu 只有一个渲染器。画布、PNG、PSD、CBZ 和 PDF 导出、页面缩略图，以及**移除**笔画读取的页面，都在 GPU 上通过 vello 用同一个绘制器绘制。因此导出结果与编辑器显示的一致，而 Koharu 即使只是打开项目也需要一块能正常工作的 GPU。

## 每次绘制都重新计算文字

文字的字号、换行位置和在框中的位置，都在每次绘制页面时计算，而不在其他地方计算。没有任何可能过时的结果被保存：更改字体、框或某个词，下一次绘制就会重新排入文字。

重绘之所以快，是因为每个图层的绘制结果按它所依赖的内容（例如文字和字体）保留，编辑后的绘制会复用该编辑未涉及的所有图层。视图只按其缩放对应的细节级别，绘制页面中显示的部分。

页面或导入的图像每边最多 32,768 像素，总计最多 268,435,456 像素。PSD 导出每边最多 30,000 像素，这是 Photoshop 自身的上限。

## 排布一行文字

- **字形整形。** 文字被拆成字体、文字体系和方向相同的片段，每段用 HarfBuzz 的 Rust 移植 HarfRust 整形一次。
- **换行。** 换行遵循 Unicode 换行规则，并且着眼整段文字而不是逐行决定。框中居中的文字会让各行长度均衡。中文用 jieba 找出词语，在词语之间换行。
- **对白框的形状。** 在对白框形状的框中，会尝试框的高度能容纳的每一种行数，选择排得最好的那一种。Photoshop 会把每行放在形状中各自范围的中央，而 Koharu 让所有行沿同一条轴居中，因此不规则的对白框里文字行也不会顺着轮廓摆动。
- **从右到左。** 阿拉伯文和希伯来文的行按 Unicode 双向算法给出的顺序排列，并从右侧开始。

## 竖排

竖排列按照 W3C 日文与中文排版需求以及 CSS 竖排，从右向左排列。

| 字符                         | 在列中的处理                                                            |
| ---------------------------- | ----------------------------------------------------------------------- |
| 拉丁字母和三位以上的数字     | 顺时针旋转 90 度                                                        |
| 不在拉丁单词中的一到两位数字 | 与 CSS 的 `text-combine-upright: digits 2` 相同，在一格内直排（纵中横） |
| `!` 和 `?`                   | 使用全角；连续两到三个时在一格内直立                                    |
| `、` 和 `。`                 | 以竖排字形放在格子的角上；中文则放在格子中央                            |
| `〜`、`…`、`—`、`・`、`：`   | 居中于列；字体没有竖排字形时旋转                                        |
| 行首的 `「` 或 `『`          | 行从括号的笔画开始，不保留其前面的半个字宽                              |

请用你选择的字体检查标点、小假名和拉丁文片段：它们的样子仍取决于字体的竖排字形和度量。

## 注音

注音的字号是基字的一半，横排时在行上方，竖排时在列右侧。与 W3C 简单注音规则一样，注音和基字中较短的一方会扩展到较长一方的长度，两端各留半份间距，因此二者居中对齐，注音也不会伸到相邻文字上。基字不会跨行拆开，带注音的行会按注音需要留出行距。

## 任何字体都能用粗体和斜体

有粗体或斜体字面的字体会直接使用它。没有的字体由 Koharu 模拟，文字工具栏的提示会显示**仿粗体**或**仿斜体**：

- **仿粗体**与 CC Wild Words 自带的粗体一样，把每个字形左右各加粗 0.02 em，并把字距加宽 0.04 em。全角字符与 CJK 字体自带的粗体一样保持宽度。本身已是粗体的字面不会再变粗。
- **仿斜体**把直立文字向右倾斜 14°，即 CSS 默认的倾斜角度。在竖排列中，每个直立字符绕自身中心倾斜，因此仍位于列的中线上。

PSD 导出会把它们写成 Photoshop 自己的仿粗体和仿斜体。

## 字体从何而来

字体缺少某个字符时，Koharu 按以下顺序尝试：

<Steps>
  <Step title='文字自己的字体，或其书体的字体'>项目的书体为该文字的书写系统设置的字体。</Step>
  <Step title='该文字书写系统中日漫黑体的字体，然后是拉丁文字的' />
  <Step title='Arial' />
  <Step title='系统针对该文字的文字体系和语言的后备字体' />
  <Step title='符号和表情字体' />
</Steps>

没有指定语言的文字，含假名时按日文处理，含谚文时按韩文处理，只有汉字时按简体中文处理，因此中文不会使用日文系统字体。符号、数字和空格使用相邻文字的字体，因此 CJK 句子的标点来自其 CJK 字体。一个字符不会被拆到两种字体中。

字体列表还包含固定到一个版本的 Koharu 字体数据集中的字体族。文字需要的字面会在排布时下载，绘制会等待下载完成；下载失败的字体族会沿后备链继续向下。
