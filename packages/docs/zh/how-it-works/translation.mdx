翻译是与你所选模型的一段对话，按页面顺序每页一轮。每页翻译时都能看到之前的页面，因此人名、语气和反复出现的术语会在页面之间延续。

## 每个项目一段对话

对话属于打开的项目，只在项目打开期间存在。翻译一页就增加一轮；翻译部分文本块也是同一段对话中的一轮。更改模型、目标语言或**附加指示**会开始新的对话，因为原有历史是在旧设置下写成的。

前面的页面提供上下文，因此请从章节的第一页开始翻译。单独翻译后面的某一页，只能参考对话中已有的轮次。

## 模型收到什么

Koharu 的系统提示词是 Index-Translate 针对结构化数据的指令，使用英语，并以英文名称指明目标语言：

```text
Translate the manga text in each message into English. Each message is a page's texts as a JSON object, numbered in reading order: translate only the values, and never alter the structure or the keys. Output only the translated JSON, without any explanation.
```

你的**附加指示**按原样接在其后，可以用任何语言书写。由于回答要按 JSON 读回，提示词本身无法更改。

每页的一轮是该页未锁定的文字，按阅读顺序以编号为键排列：

```json
{
  "1": "おい、待てよ！",
  "2": "あいつ、どこへ行った…？"
}
```

文字达到 10 段或以上时，键会变成两位数，如 `01` 到 `12`，以便按阅读顺序排列。回答必须返回每一个键且不多出其他键，并被约束为这种结构。开启**视觉**时，页面扫描图会以长边 1,280 像素放在文字之前发送；不能读取图像的模型则不发送。

## 对话保留的内容

历史记录保留每页的文字及其回答，但不保留图像或模型的推理，因此它只随文字增长，本地模型也能在各轮之间复用它。接近模型的上下文窗口时，较早的页面会被折叠成由模型自己写的摘要，对话从摘要继续。纯翻译模型无法写摘要，因此会直接丢弃较早的页面。

以 **OpenAI 兼容**方式连接的服务器不会告知自己的上下文窗口，因此请在**设置 → 提供商**中设置其**上下文长度**。不设置时，历史会一直增长，直到服务器截断提示词。

## 何时重新请求某页

如果某页没有得到 Koharu 可用的回答，会按原因重新请求：

| 原因                                       | 重新请求的方式                             |
| ------------------------------------------ | ------------------------------------------ |
| 回答格式损坏或缺少某段文字                 | 一次，并告知哪里不对                       |
| 文字不同，回答却照抄了上一页的回答         | 一次，去掉它照抄的历史                     |
| 服务商因内容拦截了该页或其回答             | 一次，去掉可能正是被拦截内容的历史         |
| 该页超出模型的上下文窗口                   | 一次，丢弃较早一半的历史                   |
| 本地模型的回答被截断，例如不断重复同一内容 | 两次，每次提高随机性，否则会得到相同的回答 |

仍未得到回答或译文为空的页面，会保持未翻译且不进入历史，[任务会继续](/zh/guides/processing#查看进度与停止)。使用托管模型时，每次重试都是一次额外的请求。服务商过载或限制速率时，会在结束任务前重新发送请求，最多九次，持续约两分半钟，或按服务商要求的时长。

## 保持原样的文字

模型原样返回的文字，例如版权声明或 `!?`，本身已经是目标语言的文字。它会保留原来的字迹：清理被隐藏，也不会有译文。

## 视觉与推理

**视觉**让模型看到每页，**推理**让模型在回答前思考。在 Koharu 自己用 Index-Translate 9B 测试的 16 页上，两者都没有让翻译更好，反而都更耗时，因此默认关闭视觉，推理使用模型自己的等级。如果模型不接受你设置的等级（例如对总会推理的模型设置**关闭**），任务会停止并指出该设置。

## 获得更好的译文

- 先修正 OCR：模型翻译的是原文，而不是扫描图。
- 把人名、术语、敬称和语气写进**附加指示**，并在几页上测试。
- 从章节开头开始翻译，让后面的页面能参考前面的页面。
- 锁定已完成的译文：重新运行不会改写它，它也会从该页的这一轮中排除。
