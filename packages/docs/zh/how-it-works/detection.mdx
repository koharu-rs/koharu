检测读取一次扫描图，写入页面的结构：分格、对白框，以及每段文字和每个拟声词各一个文本块。随后 OCR 读取每个文本块的文字。后续阶段所做的一切，都从这两步写入的内容开始。

## 检测找到什么

**Koharu Layout HighRes** 是一个 RF-DETR 分割模型，会在页面上找出四类内容：文字、拟声词、对白框和分格。每一项都有框、像素蒙版和置信度。低于该类阈值的检测会被丢弃；**设置 → 流水线**中的阈值默认使用模型自己的值。模型有时会对同一个对象预测两次，因此与同类中置信度更高的检测大部分重叠的检测，以及嵌套在另一段文字中的文字，会作为重复项被丢弃。

## 阅读顺序

检测按日本漫画读者的方式排列页面：逐个分格阅读，读完一个分格的所有文字再读下一个分格。在分格之间，以及在一个分格的文字之间，它都会在留白处把页面分成从上到下阅读的行，否则分成从右到左阅读的列，再用同样的方法排列每一部分。

- 框的四分之一以上位于某个分格内的文字，在该分格中阅读。
- 大部分位于所有分格之外、但紧挨着某个分格的文字（例如溢出分格边缘的对白框，或页边的说明文字），会与高度覆盖其一半以上的最近分格一起阅读。

这个顺序就是**故事**列出的顺序，也是翻译把文字发给模型的顺序。对于从左到右阅读的书，请在**图层**中拖动行，排成正确的顺序。

## 对白框及其空间

对白框的轮廓根据其蒙版描出。一个对白框中有多段文字时，轮廓会被分成每段文字各一个空间，每段译文放在自己的空间里：

- 两个重叠绘制的对白框，先沿着两条轮廓交汇处的凹口之间的连线分开。
- 仍共用一部分的文字，在它们之间变窄的地方分开。

空间如何变成译文的框，参见[译文的排入](/zh/how-it-works/lettering)。

## 每个文本块得到什么

| 字段 | 检测写入的内容                                                                      |
| ---- | ----------------------------------------------------------------------------------- |
| 位置 | 在对白框中，或独立位于分格或页面上                                                  |
| 角色 | 文字，或拟声词                                                                      |
| 框   | 包围文字的框                                                                        |
| 方向 | 按倾斜角度看，文字块纵向更长时为竖排                                                |
| 倾斜 | 文字块边缘最常见的方向，在 45° 以内；使行末端移动不到一个笔画宽度的倾斜视为没有倾斜 |
| 文字 | 字号、线宽、墨色和描边颜色                                                          |
| 蒙版 | 文字的像素，向外扩展 3 像素以覆盖字形轮廓的细碎部分，但不会进入其他文字的框         |

画面上的文字常带描边，例如黑字白边。Koharu 根据哪种色调一直环绕着它所包围的部分，来区分描边和墨色。之后翻译会使用相同的颜色，并把描边作为线条来嵌字。

蒙版不会进入相邻的框，是因为文本块的清理透过蒙版显示：那里的清理会盖住相邻的译文。同时落在两个蒙版中的字形，归框离它更近的文本块。

## 再次检测

检测会替换页面的分格、对白框和文本块，不论它们由谁创建，但锁定的除外。锁定的图层会连同包含它的分格和对白框一起保留，检测也不会在保留的文本块上再添加一个文本块。在用新阈值等重新检测之前，请先锁定已经完成的文字。

## OCR

OCR 从每个文本块框内的扫描图读取原文。框可能延伸到相邻的文字上，因此裁切区域中页面其他文本块的字形会先用裁切区域的中位色涂掉。OCR 会把等待中的页面最多 8 页合并为一批读取。

| 识别器       | 可读取                 |
| ------------ | ---------------------- |
| Hayai OCR    | 日文、中文、韩文和英文 |
| Manga OCR AR | 日文漫画               |
| Baberu OCR   | 日文漫画               |

OCR 只读取已存在的文本块：检测漏掉的文字，换识别器也无法找回。

## 有遗漏时

| 看到的情况     | 处理方法                                                        |
| -------------- | --------------------------------------------------------------- |
| 文字没有文本块 | 用**文本块**工具（`K`）画出，再从**故事**中它的菜单运行 **OCR** |
| 文字顺序不对   | 在**图层**中拖动                                                |
| 检测过多或过少 | 在几页有代表性的页面上调整阈值，再对这些页面重新检测            |
| 读取错误       | 在**故事**中修正**原文**，再重新翻译该文字                      |
| 蒙版盖住了画面 | 在**图层**中选中文本块的蒙版并擦除；清理会立即在那里隐藏        |
