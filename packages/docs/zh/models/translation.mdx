在处理选择器或**设置 → 翻译**中设置输出。运行开始时会捕获配置，后续修改应用于下一次运行。

## 语言与指令

选择目标语言，并为名字、术语、语气、代词、格式或无需翻译的内容提供简短项目级指令。在多页上测试，先修正 OCR。

## 本地量化

GGUF 可能提供多个量化版本。较小文件节省下载空间与内存，但可能损失质量；较大文件可能更慢或超出内存。托管服务自行控制推理精度。

## 生成参数

| 控制项                              | 调整内容                     |
| ----------------------------------- | ---------------------------- |
| temperature、top P、top K、min P    | 采样与随机性                 |
| repeat、frequency、presence penalty | 重复行为                     |
| 最大输出 token                      | 响应长度预算                 |
| 思考模式                            | 支持模型的额外推理           |
| 视觉输入                            | 是否向支持模型发送源页面图片 |

<Tip>从服务商默认值开始，每次只改一个变量。较高随机性容易降低名字和术语的一致性。</Tip>

思考模式可能增加延迟与 token 使用。不受支持的选项可能被忽略或导致请求被拒绝。

## 文本与视觉输入

纯文本请求发送语义原文。启用**视觉输入**后，支持的模型还会收到源页面图片。自定义 OpenAI 兼容服务需先确认图像消息支持。

生成结果仍是可编辑的项目数据。导出前请[检查译文与布局](/zh/guides/review)。
