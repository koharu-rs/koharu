---
title: '连接翻译服务商'
description: '使用本地 GGUF、托管服务或兼容模型服务器。'
icon: 'plug'
---

翻译选择器整合本地与托管后端。一次模型选择记录服务商、模型 ID、可选量化与图像输入设置。

## 可用连接

| 类型       | 服务商                                                                   |
| ---------- | ------------------------------------------------------------------------ |
| 本地推理   | 通过 llama.cpp 运行 GGUF                                                 |
| 托管模型   | Atlas Cloud、OpenAI、Gemini、Claude、Grok、MiniMax、DeepSeek、OpenRouter |
| 兼容服务器 | LM Studio、OpenAI 兼容端点                                               |
| 机器翻译   | DeepL、Google Cloud Translation、Caiyun                                  |

各服务商负责默认端点、请求映射和模型发现。可用模型可能独立于文档更新而变化。

<Steps>
  <Step title='保存连接'>
    打开**设置 → 服务商**，选择服务并填写字段。托管服务需要凭据。本地兼容服务器需要基础 URL：LM
    Studio 默认为 `http://localhost:1234`，OpenAI 兼容端点默认为
    `http://localhost:11434/v1`。本地服务器是否需要密钥由服务器决定。
  </Step>
  <Step title='选择模型'>
    打开处理选择器或**设置 →
    翻译**。打开处理选择器或设置页面时会刷新服务商发现结果。服务不可达时，即使设置仍被保存，也可能没有可选模型。
  </Step>
  <Step title='决定是否发送页面图片'>
    **视觉**默认开启，且开关对所有模型都可用。所选模型不接受图片时，Koharu
    会从请求中去掉图片。OpenAI 兼容端点默认视为支持图片，服务器无法处理图像消息时请关闭该开关。
  </Step>
  <Step title='先试一页'>检查原文 OCR，翻译当前页并审阅响应，再处理整章。</Step>
</Steps>

## 凭据与隐私

密钥保存在操作系统的安全凭据服务中。非秘密的端点设置写入 `~/.koharu/config.toml`。

本地模型下载后在设备内处理提示词与文本。托管服务会收到请求内容，并适用其自身保留政策。本地检测与 OCR 不代表托管翻译也在本地执行。

<Warning>不要把密钥写进项目指令、文本图层或配置文件。请通过**设置 → 服务商**保存凭据。</Warning>
