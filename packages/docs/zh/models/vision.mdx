打开**设置 → 流水线**，为每个阶段选择模型。所有模型都在你的设备上运行；无论选择哪个，[工作流](/zh/guides/processing)都保持不变。

## 检测

**Koharu Layout HighRes** 是一个 RF-DETR 分割模型，可找出分格、对白框、文字和拟声词，并为每个文本块确定蒙版和阅读顺序。

文本、拟声词、气泡和分格阈值决定各类别所需的置信度；留空时使用模型自身的值。降低阈值会保留更多不确定区域，也可能增加误检。修改前请比较多张有代表性的页面，然后对这些页面重新运行检测。

## OCR

| 模型                                                                             | 识别内容               |
| -------------------------------------------------------------------------------- | ---------------------- |
| [Manga OCR AR](https://huggingface.co/muscgab/manga-ocr-ar-experimental)         | 日文漫画文字（默认）   |
| [Baberu OCR](https://huggingface.co/genshiai-daichi/baberu-ocr)                  | 日文漫画文字           |
| [Hayai OCR](https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.7-supernova) | 日文、中文、韩文和英文 |

Manga OCR AR 采用 CC BY-NC-SA 4.0 许可，因此保持默认设置时只能用于非商业用途。各模型的许可请查看其模型卡。

<Note>
  OCR 读取已检测的文本块。文字缺失时请先检查检测结果：更换识别模型无法找回从未被检测到的文本块。
</Note>

## 修补

<Tabs>
  <Tab title="直接修复">经过漫画微调的 **LaMa** 是默认模型，适合日常的文字去除。</Tab>
  <Tab title="生成式">
    **FLUX.3 Klein** 和 **Qwen-Image 2.1 Turbo** 通过 stable-diffusion.cpp 运行，并遵循**设置 → 流水线**中的**提示词**；默认提示词要求模型去除所有文字并保持其他内容不变。

    这些模型需要更多下载空间、内存和时间。提示词应描述去除文字的要求，译文请用文本图层排版。Qwen-Image 2.1 Turbo 采用 Qwen Research License，仅限研究和评估用途。

  </Tab>
</Tabs>

纯色和平滑背景无需任何模型即可填充，因此模型的差别主要体现在线稿和网点上的文字。参见[清理](/zh/guides/cleanup)。

## 首次运行

模型首次加载时会从 Hugging Face 下载固定到某次提交的权重，并保持加载，直到设置切换到其他模型。首次运行包含下载和加载时间，因此在选择项目默认模型前，请在相同页面上比较已加载的模型。
