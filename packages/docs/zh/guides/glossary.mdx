术语表用于统一人物名、地点名及作品专有词的译名。每份术语表归当前项目所有，并随项目保存。

打开一个项目，然后选择右侧边栏中的**术语表**标签。未打开项目时，此标签不可用。

## 扫描项目

只有当你选择**扫描术语表**或**重新扫描术语表**时，扫描才会开始。

<Steps>
  <Step title='运行扫描'>
    Koharu 会先对整个项目运行检测与 OCR。所有页面完成 OCR
    后，本地术语识别才会读取最新源文本。进度会从**正在准备 OCR**进入**正在识别术语**。
  </Step>
  <Step title='检查结果'>
    扫描完成后，面板会显示**可用**和**等待确认**。扫描不会自动翻译术语，也不会开始常规正文翻译。
  </Step>
  <Step title='源文本变化后重新扫描'>
    修改 OCR
    源文本或其语言、添加或删除源文本、调整页面顺序后，源文本快照会发生变化，术语表会显示**需要重新扫描**。请先选择**重新扫描术语表**，再依据列表处理术语。
  </Step>
</Steps>

重新扫描会更新置信度、出现次数、示例及每条术语在最新扫描中的出现状态。现有译名与启用状态会保留。最新扫描未识别到的术语也会保留，并标记为**最新扫描中未出现**，你可以自行检查或删除。

<Note>
  **需要重新扫描**表示 OCR
  源文本变化后，整份术语表已过期。**本次未出现**表示某一条术语没有出现在最近完成的扫描中。
</Note>

在 OCR 阶段停止任务时，已经提交的 OCR 结果会保留，术语表不会更新。在本地术语识别阶段停止或扫描失败时，Koharu 不会保存部分扫描结果。关闭或切换项目也会请求停止当前扫描。

如果本地术语识别期间 OCR 源文本发生变化，Koharu 会丢弃本次扫描结果并要求重新扫描。

## 检查与编辑术语

搜索会匹配源词和译名。你可以同时使用类别筛选，以及**已翻译**、**未翻译**、**已禁用**、**本次未出现**状态筛选。

每条术语可显示以下内容：

- 源词、译名与类别；
- 识别置信度（如有）；
- 出现次数，以及源词与译名的来源；
- 项目中的简短示例；
- 是否出现在最新扫描中。

你可以在条目中直接编辑源词、译名和类别。每条术语都有独立开关，用于控制该术语是否参与后续翻译。打开**术语表操作**并选择**添加术语**可以手动新增内容。你也可以删除单条术语，或选择多条术语后批量删除。**选择可见术语**仅选择当前搜索与筛选结果中的条目。

面板顶部的开关控制整份项目术语表是否用于常规正文翻译。只有在整份术语表已启用、条目自身已启用且译名非空时，该条目才会用于正文翻译。

## 自动翻译术语

Koharu 可以使用处理设置中当前选择的翻译模型，为未翻译术语填写译名。

- 选择若干条目并点击**翻译所选术语**，即可翻译其中已启用且未翻译的术语。
- 选择**术语表操作 → 翻译未译术语**，即可翻译项目中所有已启用且未翻译的术语。

术语表必须有目标语言，当前提供商也必须支持该目标语言与系统提示词。若条件不满足，Koharu 会显示错误，术语表不会发生变化。所有返回的译名会在最后统一保存一次。如果提供商请求失败，或 Koharu 在最终保存开始前检测到停止请求，所有条目都保持不变；保存一旦开始便无法撤销。

在用于正文前，请检查自动生成的译名。你可以直接编辑条目来替换生成结果。

## 开始正文翻译

扫描术语表与自动翻译术语都属于准备步骤。术语检查完成后，按以下步骤翻译正文：

<Steps>
  <Step title='启用术语表'>打开面板顶部的**启用术语表**，并确认需要使用的每条术语都已启用。</Step>
  <Step title='明确启动正文翻译'>
    使用常规处理选择器或**处理**菜单运行翻译。范围与阶段行为详见[处理页面](/zh/guides/processing)。
  </Step>
  <Step title='检查页面'>
    结合完整译文检查名称与术语。详见[检查文字与图层](/zh/guides/review)。
  </Step>
</Steps>

任务开始时，Koharu 会为所有已启用且译名非空的条目创建一个快照。整个处理任务都会使用同一份快照；即使页面处理期间又编辑了术语表，当前任务也不会改变。请启动新的翻译任务以使用后续修改。

<Warning>
  当术语表已启用且包含已启用、已有译名的条目时，DeepL、Google Cloud Translation 与 Caiyun
  无法运行正文翻译。这些提供商无法接收术语表所需的系统提示词。Koharu
  会显示能力错误，也不会绕过术语表继续处理。请在[提供商设置](/zh/models/providers)中选择支持系统提示词的提供商；若你明确希望在不使用术语表的情况下翻译，也可以关闭**启用术语表**。
</Warning>

## 导入与导出 JSON

选择**术语表操作 → 导出术语表**，浏览器会下载一个 JSON 文件。导出内容包括源语言、目标语言，以及每条术语的源词、译名、类别与启用状态。扫描置信度、示例、出现次数和项目修订号只保留在当前项目中。

如需在另一项目复用术语，请打开目标项目的术语表并选择**导入术语表**。Koharu 会在浏览器中读取所选 JSON 文件，并预览新增、冲突和相同条目的数量。

请选择冲突处理方式：

- **保留现有内容**：冲突时保留当前项目中的值。
- **替换现有内容**：冲突时使用导入文件中的值。

对于源语言和目标语言，只有项目术语表与导入文件都指定了非空值且两者不同时，Koharu 才会报告差异并要求明确确认。若项目术语表缺少对应的语言信息，导入时会采用文件中的值。导入的术语不会被翻译，也不会转换为其他语言。

术语表由各项目独立拥有，没有跨项目实时共享或全局术语表。跨项目复用需要明确导出并导入 JSON。项目存储与备份方式详见[项目与导入](/zh/guides/projects)。

## 编辑期间项目发生变化

术语表编辑会依据当前项目修订号提交。如果其他操作先更新了项目，Koharu 会提示修订冲突并刷新术语表，也不会自动重放已经过期的编辑。请检查刷新后的条目，再按需重新修改。切换项目时，选中项与待处理的导入状态会被清除，上一项目的结果不会显示在新项目中。
