title: '清理原文字迹'
description: '使用修补和移除工具去除文字，同时保留图稿。'
---

修补会重建原文字迹下方的图稿。精确的移除区域通常比更大的模型更重要。

## 检查自动清理

检测会为每个文本块生成覆盖原文字形的蒙版，范围比字形略大几个像素，但不会进入其他文字的框。修补会填充每个蒙版，并把结果保存为该文本块的清理，显示在译文下方。重新运行修补会替换清理结果。

大多数文字位于白纸或渐变上，因此在周围像素允许时，Koharu 不调用模型即可填充：

| 周围                         | 填充方式                            |
| ---------------------------- | ----------------------------------- |
| 单一纯色                     | 该颜色                              |
| 平滑背景                     | 源自 OpenCV 的 Telea 快速行进法填充 |
| 线稿、网点、对白框边线或画面 | 修补模型                            |

在单一纯色上，蒙版中彼此分离的部分会各自判断，因此零散的部分会使用其周围的颜色填充。蒙版盖住对白框边线或画面时，模型只重绘那一部分。各层级如何判断，参见[清理的工作原理](/zh/how-it-works/cleanup)。

模型会以页面原本的比例，带上每段文字周围 256 像素的上下文进行重绘，且不会跨越两个分格。LaMa 的填充只保留在蒙版内。FLUX.3 Klein 和 Qwen-Image 2.1 Turbo 会重绘整个区域，清理会保留文字周围的重绘结果，并透过文本块的蒙版显示，因此把蒙版涂得更大即可显示更多重绘内容。

请以正常阅读尺寸和高倍缩放检查结果，留意字形残片、遗漏的标点或注音、被擦掉的对白框边线、重复纹理以及被抹糊的网点。

## 修复遗漏区域

<Steps>
  <Step title='涂抹区域'>
    选择**移除**，设置画笔大小，只覆盖需要重建的原文字迹。用可控的笔画涂抹，避开相邻线稿。
  </Step>
  <Step title='等待修补'>
    松开笔画后，Koharu
    会立即用所选修补模型修补该区域。结果会画在**图层**中选中的栅格图层上；没有选中时，会新建一个栅格图层并保持选中，后续笔画也会画在上面。如果选中的是文本块的清理，结果会画在译文下方的清理里，文本块的蒙版也会随之扩大。修补基于当前看到的页面（不含译文文字），因此在结果上再次涂抹可以继续修整。
  </Step>
  <Step title='修整并检查'>
    使用**取色器**、**绘画**和**橡皮擦**进行小范围的确定性修正，再以正常缩放检查。
  </Step>
</Steps>

想重做某段文字时，删除它的文本块：清理结果会一并删除，原来的文字会重新显示。

## 选择模型

在**设置 → 流水线**中选择修补模型。默认的 **LaMa** 不使用提示词。**FLUX.3 Klein** 和 **Qwen-Image 2.1 Turbo** 是生成式替代方案，会遵循同一页面中的**提示词**，并需要更多内存和时间。参见[视觉与图像修复模型](/zh/models/vision)。

<Warning>
  **绘画**和**移除**的笔画会落在选中的栅格图层上。若要画在新图层上，请先清除选择。重新运行修补会替换清理，其中的笔画也会一并替换。
</Warning>
