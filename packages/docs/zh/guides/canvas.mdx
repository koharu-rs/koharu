工具栏决定指针操作，检查器修改所选图层的持久属性。

## 导航与选择

用**平移**移动视图，通过状态栏调整缩放。**视图 → 适应窗口**或默认的 `0` 会显示完整页面。切换页面会回到适应视图。

用**选择**选中可编辑图层，配合修饰键多选。受支持图层可以移动、缩放和旋转。拖动时预览变换，结束时提交，取消则恢复之前的呈现。

## 选择编辑工具

<Tabs>
  <Tab title='文本'>
    单击创建点文本，拖动创建段落框。在检查器中输入译文，再设置[排字与适配](/zh/guides/typesetting)。
  </Tab>
  <Tab title='画笔与橡皮擦'>
    **画笔**按所选颜色和直径绘制手动栅格图层；**橡皮擦**移除手动栅格目标的像素。这些修改与模型生成的修复结果分开保存。
  </Tab>
  <Tab title='取色器'>从合成后的画布取色，用于笔画或文字样式。</Tab>
  <Tab title='移除'>
    绘制蒙版后运行图像修复。蒙版指定需要重建的原文字迹，不会成为可见涂层。详见[清理原文](/zh/guides/cleanup)。
  </Tab>
</Tabs>

<Tip>按住 `Space` 拖动可临时平移，松开后恢复原工具。`Escape` 取消当前手势或清空选择。</Tip>

输入框获得焦点时，单键工具快捷键不生效。查看[快捷键](/zh/reference/shortcuts)。
