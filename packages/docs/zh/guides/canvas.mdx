画布上的工具栏用于选择工具。**属性**用于编辑所选图层保存的值。

## 浏览与选择

使用**平移**工具移动视图，使用状态栏中的缩放滑块调整缩放。**视图 → 适应窗口**（默认快捷键 `0`）会让当前页面完整显示。切换页面时会适应新页面。

使用**选择**工具选取图层。点击图层；按住 `Shift`、`Ctrl` 或 `Command` 点击可添加或移除；从空白处拖动可框选。拖动选中内容即可移动。单选时显示缩放和旋转手柄；多选时只能移动。锁定的图层不会移动。

## 选择编辑工具

<Tabs>
  <Tab title='文本'>
    使用**文本**点击可创建点文字，拖动可创建文本框。直接输入文字，然后调整[排版](/zh/guides/typesetting)。选中文本块或文本图层时，**文本**工具可就地编辑其译文。
  </Tab>
  <Tab title='绘画与橡皮擦'>
    **绘画**会用所选颜色和大小在选中的栅格图层上绘制；未选中栅格图层时，会在页面最上层新建一个栅格图层。**橡皮擦**需要先选中栅格图层。两者都不会作用于隐藏或锁定的图层。按住
    `Alt` 滚动可调整大小。
  </Tab>
  <Tab title='取色器'>
    使用**取色器**点击，可拾取指针下页面本身的像素。拾取的颜色会成为笔刷颜色；如果是从颜色字段的**从画布拾取颜色**开始，则成为该字段的颜色。
  </Tab>
  <Tab title='移除'>
    用**移除**涂抹原文字迹。松开笔画后会立即修补该区域，并把结果添加为一个仅限于涂抹区域的新栅格图层。参见[清理](/zh/guides/cleanup)。
  </Tab>
</Tabs>

<Tip>
  按住 `Space` 或鼠标中键拖动，可在不切换工具的情况下平移。滚动可平移，按住 `Shift` 可水平平移，按住
  `Ctrl` 或 `Command` 可围绕指针缩放；触控板双指捏合也可缩放。按 `Escape` 清除选择。
</Tip>

文本字段获得焦点时，单键工具快捷键不会生效。参见[键盘快捷键](/zh/reference/shortcuts)。
