---
title: '使用画布'
description: '浏览页面，并为文字、图稿和清理选择合适的工具。'
---

画布上的工具栏用于选择工具。右侧的**图层**用于编辑当前页面的图层，**故事**用于编辑所有页面的文字，选中文字旁边出现的工具条用于设置其排版。

## 浏览与选择

使用**平移**工具移动视图，使用状态栏中的缩放滑块调整缩放。**视图 → 适应窗口**（`Ctrl+0` 或 `Command+0`）会让当前页面完整显示。切换页面时会适应新页面。

使用**选择**工具选取图层。点击图层；按住 `Shift`、`Ctrl` 或 `Command` 点击可添加或移除；从空白处拖动可框选。拖动选中内容即可移动。单选时显示缩放和旋转手柄；多选时只能移动。锁定的图层不会移动。

## 选择编辑工具

<Tabs>
  <Tab title='直接选择'>
    用**直接选择**选中文本块或文本图层，会显示其文本框的锚点。拖动锚点或线段可改变文本框的形状；按住
    `Shift` 单击可加选锚点；从空白处拖动可框选锚点。按 `Delete` 或 `Backspace`
    删除选中的锚点，文本框至少保留三个锚点。松开拖动后，文字会适配新的形状。
  </Tab>
  <Tab title='矩形选框与套索'>
    与 Photoshop
    一样，用**矩形选框**拖动可选中页面上的矩形区域，用**套索**拖动可选中任意形状的区域。开始拖动时按住
    `Shift` 可添加到选区，按住 `Alt` 可从选区中减去。不拖动直接单击，或按 `Ctrl+D` 或 `Command+D`
    可取消选择。选区下方的工具栏即**创成式填充**。选择它绘制所用的模型（默认为 FLUX.3
    Klein）：这是填充专用的模型，与**设置 →
    流水线**中用于清理页面和**移除**笔触的修补器分开。描述要画的内容并选择**生成**，或将提示词留空以使用**设置
    →
    流水线**中的**提示词**。结果会作为限定在选区内的新栅格图层添加，图层以提示词命名。选区会保留，可以再次生成；设置中未使用的填充模型会在最后一次运行后保持加载五分钟，因此再次生成时无需重新加载。LaMa
    不使用提示词，因此选用 LaMa 时工具栏没有提示词输入框。
  </Tab>
  <Tab title='文本'>
    使用**文本**点击可开始输入点文字，拖动可开始输入文本框，像在 Photoshop
    中一样直接在画布上输入。用**文本**点击某段文字，或用**选择**双击它，即可从点击处开始输入；拖动可选择文字，双击可选中一个词。按
    `Ctrl`+`Enter` 或数字键盘上的 `Enter` 确认输入，点击别处或换用其他工具也会确认；按 `Esc`
    放弃输入。每次输入算作一步撤销，新文字只有输入了字符后才会添加。然后调整[排版](/zh/guides/typesetting)。
  </Tab>
  <Tab title='文本块'>
    用**文本块**在检测遗漏的文字上拖出一个框。它会在框下的对白框或分格中添加一个文本块，以该框作为文本框和蒙版。然后在**故事**中用它菜单里的
    **OCR** 识别。若要保留文字周围的画面，请把蒙版涂小。
  </Tab>
  <Tab title='绘画与橡皮擦'>
    **绘画**会用所选颜色和大小在选中的栅格图层上绘制；未选中栅格图层时，会在页面最上层新建一个栅格图层。**橡皮擦**需要先选中栅格图层。两者也可以作用于在**图层**中选中的文本块清理结果或蒙版：在蒙版上，**绘画**会显示更多清理结果，**橡皮擦**会将其隐藏。两者都不会作用于隐藏或锁定的图层。按住
    `Alt` 滚动可调整大小。
  </Tab>
  <Tab title='取色器'>
    使用**取色器**点击，可拾取指针下页面本身的像素。拾取的颜色会成为笔刷颜色；如果是从颜色字段的**从画布拾取颜色**开始，则成为该字段的颜色。
  </Tab>
  <Tab title='移除'>
    用**移除**涂抹原文字迹。松开笔画后会立即修补该区域。结果会画在**图层**中选中的栅格图层或文本块的清理上；两者都未选中时，会新建一个栅格图层并保持选中，后续笔画也会画在上面。参见[清理](/zh/guides/cleanup)。
  </Tab>
</Tabs>

<Tip>
  按住 `Space` 或鼠标中键拖动，可在不切换工具的情况下平移。滚动可平移，按住 `Shift` 可水平平移，按住
  `Ctrl` 或 `Command` 可围绕指针缩放；触控板双指捏合也可缩放。按 `Escape` 清除选择。
</Tip>

文本字段获得焦点时，单键工具快捷键不会生效。参见[键盘快捷键](/zh/reference/shortcuts)。
