不带 `--headless` 启动时，Koharu 会打开桌面编辑器。`koharu --headless` 不会创建桌面 CEF 窗口。它把现有的编辑器 Web UI 提供给系统浏览器使用。

## 在浏览器中打开编辑器

<Tabs>
  <Tab title="macOS 与 Linux">
    ```bash
    koharu --port 4000 --headless
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    koharu.exe --port 4000 --headless
    ```
  </Tab>
</Tabs>

打开终端打印的 URL，默认是 `http://127.0.0.1:4000/`。使用编辑器期间请保持该进程运行，结束时按 `Ctrl+C`。

浏览器中的界面是同一套应用，通过浏览器传输连接。无窗口模式不提供 MCP 或 OpenAPI。

<Note>
  画布需要浏览器中的 WebGPU。请使用带有可用显卡驱动的较新版 Chrome 或
  Firefox。参见[硬件与运行时](/zh/hardware)。
</Note>

## 参数

| 参数         | 作用                                     |
| ------------ | ---------------------------------------- |
| `--headless` | 通过 HTTP 提供编辑器，不打开桌面窗口     |
| `--port`     | 绑定端口，默认 `4000`                    |
| `--host`     | 绑定地址，默认 `127.0.0.1`               |
| `--download` | 准备运行时和模型后退出                   |
| `--cpu`      | 即使有 GPU 也使用 CPU 推理               |
| `--debug`    | 启用调试控制台输出                       |

默认主机为 `127.0.0.1`，默认端口为 `4000`。在发行版中，如果省略 `--port` 且该端口已被占用，Koharu 会依次尝试更大的端口直到绑定成功。显式指定 `--port` 时只绑定该端口。

`--download` 会准备运行时和模型，然后退出，不会启动编辑器。`--cpu` 会选择 CPU 推理。

## 网络访问

访问 localhost 时没有身份验证。绑定 `--host 0.0.0.0` 是有意且未受保护的：能连到该端口的人都可以使用编辑器。对非回环地址公开时，请配合防火墙、反向代理或自行提供的身份验证。
