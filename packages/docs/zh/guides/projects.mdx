项目保存原图、分析结果、文本、图像编辑和呈现信息。Koharu 将工作写入 `.khrproj` 目录，不会覆盖导入源。

## 创建与重新打开

开始界面列出系统文档目录中的项目：

```text
Documents/
  Koharu/
    My Project.khrproj/
```

可在这里创建、打开或删除项目。名称不能包含路径分隔符或系统保留字符。关闭当前项目即可返回列表。

<Warning>删除项目会永久移除整个目录，无法用会话撤销恢复。</Warning>

## 导入页面

<Steps>
  <Step title='选择文件或文件夹'>
    用**文件 → 导入页面 → 文件**选择图片、压缩包或
    PDF。选择**文件夹**可递归扫描。导入前请等待当前处理任务完成。
  </Step>
  <Step title='检查顺序'>
    图片路径和压缩包条目按自然顺序排列，例如 `page2.png` 在 `page10.png` 之前。PDF
    保留文档顺序。文件夹导入跳过不支持的文件，不跟随符号链接。
  </Step>
  <Step title='整理页面栏'>
    选择单页或范围、重命名、拖动排序，或确认后删除。页面顺序决定处理顺序和导出文件名前缀。
  </Step>
</Steps>

| 来源                               | 导入结果                     |
| ---------------------------------- | ---------------------------- |
| PNG、JPEG（`.jpg`、`.jpeg`）、WebP | 每张图片一页                 |
| CBZ、ZIP、RAR                      | 每个受支持的图片条目一页     |
| PDF                                | 每个文档页面栅格化为无损图片 |

源数据会复制到按内容寻址的项目存储中。移动或删除原文件不会移除已导入页面。

## 备份与恢复

关闭项目，再复制**整个** `.khrproj` 目录。状态文件和 blob 缺一不可。恢复时先关闭 Koharu，再将完整目录放回 `Documents/Koharu`。

<Note>关闭项目会保留最新保存状态，但清空会话内的撤销与重做历史。</Note>
