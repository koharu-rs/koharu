项目保存源图像、文字、图稿编辑和版面。Koharu 把每个项目保存为一个 `.khr` 文件，不会修改你导入的文件。每次编辑都会立即保存，因此没有**保存**命令。

## 创建与重新打开项目

开始界面按最近修改顺序列出 Koharu 项目文件夹中的项目：

| 平台    | 项目文件夹                                      |
| ------- | ----------------------------------------------- |
| Windows | Koharu 安装文件夹中的 `projects`                |
| macOS   | `~/Library/Application Support/Koharu/projects` |
| Linux   | `~/.local/share/Koharu/projects`                |

可在此创建、打开或删除项目。项目名称就是文件名，因此在任一平台上不能作为文件名的名称会被拒绝。选择**文件 → 关闭项目**可返回开始界面。

<Warning>删除项目会在确认后永久删除其文件，无法撤销。</Warning>

## 导入页面

<Steps>
  <Step title='选择文件或文件夹'>
    打开**文件 → 导入页面 → 文件…**，选择图像、压缩包或
    PDF。选择**文件夹…**，则会导入该文件夹中直接包含的受支持文件，不会搜索子文件夹。
  </Step>
  <Step title='检查导入顺序'>
    文件和压缩包内的条目按名称排序，其中的数字按数值比较：`page2.png` 在 `page10.png` 之前。PDF
    保持文档页序。新页面会添加到项目最后一页之后。
  </Step>
  <Step title='整理页面列表'>
    使用 `Ctrl`、`Command` 或 `Shift`
    选择页面，可拖动页面调整位置，或从操作菜单删除页面。删除可以撤销。页面顺序决定处理和导出顺序。
  </Step>
</Steps>

| 来源                               | 导入结果                                          |
| ---------------------------------- | ------------------------------------------------- |
| PNG、JPEG（`.jpg`、`.jpeg`）、WebP | 每张图像一页                                      |
| ZIP、CBZ、RAR、CBR                 | 每个 PNG、JPEG 或 WebP 条目一页，其他条目会被跳过 |
| PDF                                | 每个文档页面按 300 DPI 渲染为一页                 |

操作系统留在压缩包中的文件（例如 macOS 的 `__MACOSX` 资源分支）会被跳过。导入的数据会复制进项目文件，因此移动或删除原文件不会影响项目。

## 备份与恢复

先关闭项目，再复制它的 `.khr` 文件。恢复时请关闭 Koharu，把文件放回项目文件夹。

<Note>关闭项目会保留所有工作，但会清除撤销与重做历史。同一个项目一次只能在一个窗口中打开。</Note>
