Give the Agent a concrete goal within the open project. Name the pages, the change you want, and anything it should leave untouched.

## Write a scoped request

<Tabs>
  <Tab title="Text review">
    > Review pages 3–5. Correct obvious OCR errors and translate into natural English while preserving honorifics. Keep typography unchanged.
  </Tab>
  <Tab title="Visual review">
    > Check whether the text on page 8 overflows its bubble. Adjust only the size and line breaks.
  </Tab>
</Tabs>

Reading the project's layers is enough for many text edits. Ask for visual inspection when appearance matters.

## Available tools

| Tool          | Does                                                                                           |
| ------------- | ---------------------------------------------------------------------------------------------- |
| `get_project` | Lists the pages in order                                                                       |
| `get_page`    | Reads a page's panels, balloons, and text blocks in reading order, with source and translation |
| `get_layer`   | Reads one layer with everything inside it                                                      |
| `edit`        | Applies changes to layers and pages as one undo step                                           |
| `run`         | Starts a pipeline run on the project, some pages, some text blocks, or a painted area          |
| `wait`        | Waits up to 30 seconds for a run to end and reports what it has done so far                    |
| `stop`        | Stops every pipeline run                                                                       |
| `view_page`   | Renders a page as the editor draws it                                                          |

<Note>
  The tools do not import or export files, manage provider credentials, or work outside the open
  project.
</Note>

## Edits, cancellation, and history

Agent changes use the same edits as the editor, so they redraw the canvas as they happen and each is an undo step. Pipeline runs the Agent starts appear in the activity center like any other run.

One request runs at a time. **Cancel** stops the Agent, and an edit already being applied finishes whole. A pipeline run the Agent started keeps going; stop it from the activity center. The conversation continues across requests and ends when you change the Agent's model or close the project.

<Steps>
  <Step title='Inspect the changed pages'>Review source text, translations, and the canvas.</Step>
  <Step title='Check the layout'>Verify placement and typography at normal reading size.</Step>
  <Step title='Keep or undo the change'>
    Use undo for unwanted changes, and export after your review.
  </Step>
</Steps>
