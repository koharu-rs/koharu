Choose translation settings in **Settings → Translation**; the processing selector also sets the model and the target language. They are saved with Koharu's settings and apply to every project. Provider connections and credentials are read for each request.

## Language and system prompt

Choose the **Target language**. The **System prompt** is the instruction the model gets; `{target}` stands for the target language's English name and must appear in it. Edit it for names, terminology, tone, pronouns, or text that should remain untranslated, and test it on several pages after correcting OCR. The default is Index-Translate's own translation instruction.

LFM3 1.7B is made for a limited set of target languages. Other local and hosted models accept every target language Koharu offers.

## How pages are translated

Translation is one conversation per open project: one turn per page, in page order, so each page sees the pages translated before it. Translating selected text blocks is a turn of the same conversation. Changing the model, the target language, or the prompt starts a new one.

Each page is sent as its texts in reading order, and the answer must return every one. A malformed answer, a missing text, or a blank translation fails that page. A text the model gives back unchanged, such as a copyright line, keeps its original lettering: its clean-up is hidden and it gets no translation.

## Options

| Option    | What it does                                                                                                |
| --------- | ----------------------------------------------------------------------------------------------------------- |
| Vision    | Sends the page image, 1,280 pixels on its longer side, ahead of the texts; off by default                   |
| Reasoning | Lets the model reason before it answers, at the level you choose; **Provider default** uses the model's own |

Vision works only with a model that reads images; with any other model the run fails and asks you to turn **Vision** off. Both options add time, and on Koharu's own tests with Index-Translate 9B neither read better, so try them on a few pages before keeping them.

## Local quantization

Koharu's local models load their default quantization. To choose another, set the model in `~/.koharu/config.toml` with the quantization after a colon, for example `model = "koharu/index-translate-9b:Q8_0"` under `[pipeline.translator]`. Smaller files need less memory, usually at a quality cost. Hosted providers control their own serving precision.

Generated translations remain editable project data. [Review the wording and page layout](/guides/review) before export.
