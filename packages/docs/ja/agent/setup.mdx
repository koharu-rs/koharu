Koharu Agent はエディター内の Codex クライアントです。ChatGPT のデバイスコード認証を使い、Agent 用の OpenAI API キーは入力しません。

<Steps>
  <Step title='Agent パネルを開く'>プロジェクトを開き、右側の **Agent** を選びます。</Step>
  <Step title='デバイスを認証する'>
    **Codex でサインイン**を選ぶと、Koharu
    がブラウザーで認証ページを開きます。パネルに表示されたコードを入力し、使用するアカウントでサインインを承認します。コードは
    15 分で期限切れになります。
  </Step>
  <Step title='モデルを選ぶ'>
    Koharu に戻り、アカウントとモデル一覧の読み込みを待ちます。Agent パネル上部で Codex
    モデルと推論レベルを選びます。**自動**は利用可能な最初のモデルを使います。追加の推論は曖昧な編集に役立つことがありますが、時間がかかります。
  </Step>
</Steps>

サインインは同時に 1 回だけです。別の試行を始める前にキャンセルしてください。

## 共有される文脈

Agent は開いているプロジェクトの意味状態から始めます。画像確認ツールを呼んだときだけ、そのページを描画して添付します。全ページを自動で添付するわけではありません。

<Note>
  Agent の認証と翻訳プロバイダーの資格情報は別です。ChatGPT へのサインインでパイプラインの OpenAI
  接続は設定されず、API キーを保存しても Agent にはサインインしません。
</Note>

## サインアウト

**サインアウト**は実行中の作業をキャンセルし、Agent セッションと Koharu が使う Codex アカウント認証を削除します。プロジェクトを開いたり閉じたりしたときも会話は消去されます。Agent 設定は翻訳設定と別に保存されます。
