---
title: 'Koharu Agent のセットアップ'
description: 'エージェントのモデルを選び、ほかのプログラムのエージェントを MCP で接続します。'
---

Koharu Agent はエディターに組み込まれたプロジェクトのアシスタントです。ツールを呼び出せるモデルであれば、翻訳用に選べるどのモデルでも動きます。ホスト型モデル、ChatGPT などのサブスクリプション、Koharu の汎用ローカルモデルが使えます。

<Steps>
  <Step title='プロバイダーを接続する'>
    **設定 → プロバイダー**で API
    キーを入力するかサインインします。ローカルモデルを使う場合は不要です。[翻訳プロバイダー](/ja/models/providers)を参照してください。
  </Step>
  <Step title='エージェントパネルを開く'>
    プロジェクトを開き、右側の**レイヤー**と**ストーリー**の隣にある**エージェント**タブを選びます。
  </Step>
  <Step title='モデルを選ぶ'>
    メッセージ欄の下でモデルと推論レベルを選びます。**プロバイダーの既定値**はモデル自身のレベルを使い、**オフ**はモデルが対応していれば推論をしないようにします。推論を増やすと曖昧な編集に役立つことがありますが、時間がかかります。その横の**新しいチャット**で会話を最初からやり直せます。
  </Step>
</Steps>

## 共有されるコンテキスト

各リクエストは、開いているプロジェクトの概要（ページとそのレイヤー）から始まります。エージェントがページ画像を描画して添付するのは、ページ表示ツールを呼び出したときだけで、すべてのページを添付するわけではありません。ホスト型モデルのプロバイダーは、エージェントが送った内容を受け取ります。

<Note>
  エージェントと翻訳はプロバイダーの接続を共有しますが、モデルは共有しません。エージェントのモデルと推論は、翻訳とは別に
  `~/.koharu/config.toml` の `[agent]` セクションに保存されます。エージェントのシステムプロンプトは
  Koharu に固定されており、変更できません。
</Note>

## ほかのエージェントを MCP で接続する

Koharu の実行中は、同じツールを MCP の Streamable HTTP トランスポートでほかのプログラムのエージェントに提供します。同じマシンの MCP クライアントに次の URL を追加してください。

```text
http://127.0.0.1:7878/mcp
```

この URL は起動し直しても変わりません。Koharu の起動時にほかのプログラムがポート 7878 を使っていると、サーバーは動作しません。サーバーは開いているプロジェクトを対象に動作し、このマシンからの接続だけを受け付け、Web ページからのリクエストは拒否します。

  エージェントに明確な範囲を伝え、編集を確認し、プロジェクトの履歴を使います。
