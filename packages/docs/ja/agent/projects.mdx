開いているプロジェクトの範囲で、エージェントに具体的な目標を伝えます。対象のページ、望む変更、変えてほしくないものを明示してください。

## 範囲を指定する

<Tabs>
  <Tab title="文章の確認">
    > 3〜5 ページを確認してください。明らかな OCR ミスを直し、敬称を残して自然な英語に翻訳してください。組版は変更しないでください。
  </Tab>
  <Tab title="見た目の確認">
    > 8 ページの文字が吹き出しからはみ出していないか確認してください。サイズと改行だけを調整してください。
  </Tab>
</Tabs>

テキスト編集の多くは、プロジェクトのレイヤーを読むだけで行えます。見た目が重要な場合は画像での確認を依頼します。

## 利用できるツール

| ツール        | 内容                                                                                     |
| ------------- | ---------------------------------------------------------------------------------------- |
| `get_project` | ページを順に一覧します                                                                   |
| `get_page`    | ページのコマ、吹き出し、テキストブロックを、原文と翻訳つきで読み順に読みます             |
| `get_layer`   | 1 つのレイヤーを中身ごと読みます                                                         |
| `edit`        | レイヤーとページへの変更を 1 つの取り消しステップとして適用します                        |
| `run`         | プロジェクト、一部のページ、一部のテキストブロック、塗った範囲でパイプラインを開始します |
| `wait`        | 実行の終了を最大 30 秒待ち、ここまでの経過を返します                                     |
| `stop`        | すべてのパイプラインの実行を止めます                                                     |
| `view_page`   | エディターと同じようにページを描画します                                                 |

<Note>
  これらのツールは、ファイルの読み込みや書き出し、プロバイダーの認証情報の管理、開いているプロジェクト外での操作は行いません。
</Note>

## 編集、キャンセル、履歴

エージェントの変更はエディターと同じ編集を使うため、その場でキャンバスに反映され、それぞれが取り消しステップになります。エージェントが開始したパイプラインの実行は、ほかの実行と同じくアクティビティセンターに表示されます。

リクエストは同時に 1 つだけ実行されます。**キャンセル**するとエージェントは止まり、適用中の編集は最後まで適用されます。エージェントが開始したパイプラインの実行は続くため、アクティビティセンターから停止してください。会話はリクエストをまたいで続き、エージェントのモデルを変えるかプロジェクトを閉じると終わります。

<Steps>
  <Step title='変更されたページを確認する'>原文、翻訳、キャンバスを確認します。</Step>
  <Step title='レイアウトを確認する'>通常の閲覧サイズで配置とタイポグラフィを確認します。</Step>
  <Step title='採用するか取り消す'>不要な変更は取り消し、確認後に書き出します。</Step>
</Steps>
