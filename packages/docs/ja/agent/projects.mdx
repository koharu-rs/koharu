開いているプロジェクト内の具体的な目的を伝えます。対象ページ、変更したい内容、変更しない条件を明示してください。

## 範囲を指定する

<Tabs>
  <Tab title="文章の確認">
    > 3〜5 ページを確認してください。明らかな OCR ミスを直し、敬称を残して自然な英語に翻訳してください。組版は変更しないでください。
  </Tab>
  <Tab title="見た目の確認">
    > 8 ページの文字が吹き出しからはみ出していないか確認してください。サイズと改行だけを調整してください。
  </Tab>
</Tabs>

テキスト編集の多くは意味状態の確認だけで行えます。見た目が重要な場合は画像確認を依頼します。

## できる操作

最新の意味状態の確認、指定ページの描画、ページ名・順序の変更と削除、段落テキスト枠の追加、原文・訳文の編集、組版・形状・表示・不透明度の変更、要素の移動や削除、プロジェクト・ページ・テキスト範囲でのパイプライン実行ができます。

<Note>
  プロジェクト用ツールでは、元ファイルの読み込み、ファイルの書き出し、プロバイダー資格情報の管理、開いているプロジェクト外の操作はできません。
</Note>

## 編集、キャンセル、履歴

Agent は UI と同じプロジェクト操作を使います。成功した編集はシーン、レンダラー、リビジョン、undo 履歴を更新します。

パイプラインは完了段階を逐次コミットします。Agent が開始した実行はアクティビティセンターに表示されませんが、完了するまで他の処理はブロックされます。Agent リクエストをキャンセルすると、Agent が開始したパイプラインにも協調的な停止を要求します。同時に実行できるリクエストは 1 つです。

<Steps>
  <Step title='変更ページを確認する'>原文、訳文、キャンバスを確認します。</Step>
  <Step title='配置を確認する'>通常の閲覧サイズで形状と組版を確認します。</Step>
  <Step title='採用するか戻す'>不要な変更は元に戻し、自分で確認してから書き出します。</Step>
</Steps>
