ツールバーはポインター操作を切り替え、インスペクターは選択レイヤーの保存されるプロパティを変更します。

## 移動と選択

**パン**で表示位置、ステータスバーでズームを変えます。**表示 → ウィンドウに合わせる**、または既定の `0` でページ全体を表示します。別ページに切り替えるとフィット表示へ戻ります。

**選択**で編集可能なレイヤーを選びます。`Shift`、`Ctrl`、`Command` を押しながら選ぶと、レイヤーを選択に追加・除外できます。テキストレイヤーは移動、拡大縮小、回転できます。拡大縮小と回転のハンドルは単一選択のときだけ表示され、複数選択では移動しかできません。ドラッグ中はプレビューし、完了でコミット、キャンセルで元の表示に戻ります。

## 編集ツールを選ぶ

<Tabs>
  <Tab title='テキスト'>
    クリックでポイントテキスト、ドラッグで段落枠を作ります。インスペクターに訳文を入力し、[組版とフィット](/ja/guides/typesetting)を設定します。
  </Tab>
  <Tab title='ブラシと消しゴム'>
    **ブラシ**は選択中のラスターレイヤーに選択色と直径で描画し、ラスターレイヤーが選択されていなければ新しいペイントレイヤーを作ります。**消しゴム**にはラスターレイヤーの選択が必要です。どちらのツールもインペイントが生成したクリーンアップレイヤーを対象にでき、そこへ描画するとそのレイヤーは手動編集のレイヤーになります。`Alt`
    を押しながらスクロールすると直径を変更できます。
  </Tab>
  <Tab title='スポイト'>合成済みキャンバスから色を取得し、ブラシや文字のスタイルへ適用します。</Tab>
  <Tab title='除去'>
    **除去**で原文の文字をなぞります。ストロークを離すとその範囲のインペイントがすぐに実行され、結果はページのクリーンアップレイヤーへ統合されます。マスクはレイヤーとして残りません。他の処理ジョブの実行中はストロークが拒否されます。[画像修復](/ja/guides/cleanup)を参照してください。
  </Tab>
</Tabs>

<Tip>
  `Space`
  またはマウスの中ボタンを押しながらドラッグすると、ツールを切り替えずにパンできます。スクロールでパン、`Shift`
  を押しながらスクロールで横方向にパン、`Ctrl`
  を押しながらスクロールでポインター位置を中心にズームします。`Escape`
  は操作をキャンセルし、選択を解除します。
</Tip>

入力欄にフォーカスがある間は単一キーのツール操作は無効です。[ショートカット](/ja/reference/shortcuts)を参照してください。
