ツールバーはポインター操作を切り替え、インスペクターは選択レイヤーの保存されるプロパティを変更します。

## 移動と選択

**パン**で表示位置、ステータスバーでズームを変えます。**表示 → ウィンドウに合わせる**、または既定の `0` でページ全体を表示します。別ページに切り替えるとフィット表示へ戻ります。

**選択**で編集可能なレイヤーを選び、修飾キーで複数選択します。対応レイヤーは移動、拡大縮小、回転できます。ドラッグ中はプレビューし、完了でコミット、キャンセルで元の表示に戻ります。

## 編集ツールを選ぶ

<Tabs>
  <Tab title='テキスト'>
    クリックでポイントテキスト、ドラッグで段落枠を作ります。インスペクターに訳文を入力し、[組版とフィット](/ja/guides/typesetting)を設定します。
  </Tab>
  <Tab title='ブラシと消しゴム'>
    **ブラシ**は選択色と直径で手動ラスター層に描画し、**消しゴム**はその対象の画素を消します。生成インペイントとは別の編集です。
  </Tab>
  <Tab title='スポイト'>合成済みキャンバスから色を取得し、ブラシや文字のスタイルへ適用します。</Tab>
  <Tab title='除去'>
    マスクを描いてからインペイントを実行します。修復する原文を指定するマスクであり、見える塗りレイヤーにはなりません。[画像修復](/ja/guides/cleanup)を参照してください。
  </Tab>
</Tabs>

<Tip>
  `Space` を押しながらドラッグすると一時的にパンできます。離すと元のツールへ戻ります。`Escape`
  は操作のキャンセルまたは選択解除です。
</Tip>

入力欄にフォーカスがある間は単一キーのツール操作は無効です。[ショートカット](/ja/reference/shortcuts)を参照してください。
