description: 'インペイントと削除ツールで、画像を保ったまま文字を取り除きます。'

---

インペイントは元の文字の下にある画像を再構成します。大きなモデルより、正確な除去範囲のほうが結果を左右することがよくあります。

## 自動修復を確認する

検出は各テキストブロックに、原文の字形を覆うマスクを作ります。マスクは字形より数ピクセル広がりますが、ほかのテキストの枠には入りません。インペイントは各マスクを埋め、結果をブロックのクリーンアップとして保存し、翻訳の下に表示します。インペイントを再実行するとクリーンアップは置き換えられます。

多くの文字は白い紙やグラデーションの上にあるため、周囲のピクセルが許せばモデルを使わずに埋めます。

| 周囲                             | 埋め方                                          |
| -------------------------------- | ----------------------------------------------- |
| 単色                             | その色                                          |
| なめらかな背景                   | OpenCV 由来の Telea の Fast Marching による補完 |
| 線画、トーン、吹き出しの枠線、絵 | インペイントモデル                              |

モデルは各テキストの周囲 256 ピクセルを文脈として、ページ本来の縮尺で描き直し、2 つのコマにまたがることはありません。戻ってくるのはマスク内のピクセルだけです。

通常の閲覧サイズと高倍率で結果を確認します。字形の断片、句読点やルビの消し残し、消えた吹き出しの枠線、繰り返し模様、にじんだトーンに注意します。

## 消し残しを直す

<Steps>
  <Step title='範囲を塗る'>
    **削除**ツールを選んでブラシサイズを決め、再構成が必要な文字だけを覆います。周囲の線画を避け、丁寧になぞります。
  </Step>
  <Step title='インペイントを実行させる'>
    ストロークを離すと、選択中のインペイントモデルでその範囲がすぐにインペイントされ、塗った範囲にマスクで限定された新しいラスターレイヤーとして結果が追加されます。翻訳の文字を除いた今の見た目のページから再構成するので、結果の上をもう一度塗ると仕上がりを詰められます。
  </Step>
  <Step title='仕上げて確認する'>
    小さな確実な修正には**カラーピッカー**、**描画**、**消しゴム**を使います。通常の倍率で再確認します。
  </Step>
</Steps>

テキストをやり直したい場合は、そのテキストブロックを削除します。クリーンアップも一緒に削除され、元の文字が再び表示されます。

## モデルを選ぶ

インペイントモデルは**設定 → パイプライン**で選びます。既定の **LaMa** はプロンプトを使いません。**FLUX.3 Klein** と **Qwen-Image 2.1 Turbo** は生成系の代替で、同じ画面の**プロンプト**に従い、より多くのメモリと時間を必要とします。[画像処理モデル](/ja/models/vision)を参照してください。

<Warning>
  **描画**のストロークは、削除ツールの結果も含めて、選択中のラスターレイヤーに描かれます。手作業の修正を新しいラスターレイヤーに分けるには、描く前に選択を解除してください。
</Warning>
