プロジェクトには元画像、解析結果、テキスト、画像の編集、表示情報が保存されます。Koharu は `.khrproj` ディレクトリに保存し、読み込み元を上書きしません。

## 作成と再開

開始画面には OS のドキュメントフォルダー内のプロジェクトが表示されます。

```text
Documents/
  Koharu/
    My Project.khrproj/
```

ここで作成、オープン、削除を行います。名前にはパス区切りや OS の予約文字を使えません。プロジェクトを閉じると一覧へ戻ります。

<Warning>
  プロジェクトの削除はディレクトリ全体を完全に削除します。セッションの「元に戻す」では復元できません。
</Warning>

## ページを読み込む

<Steps>
  <Step title='ファイルかフォルダーを選ぶ'>
    **ファイル → ページを読み込む → ファイル**で画像、アーカイブ、PDF
    を選びます。**フォルダー**では再帰的に検索します。処理ジョブが終了してから読み込んでください。
  </Step>
  <Step title='順序を確認する'>
    画像パスとアーカイブ内の項目は自然順で並び、`page2.png` は `page10.png` より先になります。PDF
    は文書順を保ちます。非対応ファイルとシンボリックリンクの先は読み込みません。
  </Step>
  <Step title='ページ一覧を整理する'>
    単一ページや範囲を選び、名前の変更、ドラッグによる並べ替え、確認後の削除を行います。ページ順は処理順と書き出しファイルの番号に使われます。
  </Step>
</Steps>

| 入力                               | 読み込み結果                                 |
| ---------------------------------- | -------------------------------------------- |
| PNG、JPEG（`.jpg`、`.jpeg`）、WebP | 画像ごとに 1 ページ                          |
| CBZ、ZIP、RAR                      | 対応画像ごとに 1 ページ                      |
| PDF                                | 文書の各ページを可逆形式の画像へラスタライズ |

読み込んだデータは内容アドレス方式でプロジェクトへコピーされます。元ファイルを移動・削除しても、読み込んだページは残ります。

## バックアップと復元

プロジェクトを閉じ、`.khrproj` ディレクトリ**全体**をコピーします。状態ファイルと blob の両方が必要です。復元時は Koharu を閉じ、完全なディレクトリを `Documents/Koharu` に戻します。

<Note>
  プロジェクトを閉じると、保存済みの最新状態は残りますが、セッションの undo/redo 履歴は消えます。
</Note>
