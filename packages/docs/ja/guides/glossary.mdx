用語集を使うと、固有名詞や作品固有の用語を一貫した訳語で翻訳できます。用語集はプロジェクトごとに保存されます。

プロジェクトを開き、右サイドバーの**用語集**タブを選択します。プロジェクトを開いていない間、このタブは無効です。

## プロジェクトをスキャンする

用語集のスキャンは、ユーザーが**用語集をスキャン**または**用語集を再スキャン**を選んだときだけ始まります。

<Steps>
  <Step title='スキャンを実行する'>
    最初に、プロジェクト全体へ検出と OCR を実行します。すべてのページの OCR
    が完了した後、最新の原文を使ってローカルで用語を抽出します。進捗表示は **OCR
    を準備中**から**用語を抽出中**へ移ります。
  </Step>
  <Step title='結果を確認する'>
    完了すると、パネルに**利用可能**と**確認待ち**が表示されます。スキャンだけでは用語の自動翻訳も通常の本文翻訳も始まりません。
  </Step>
  <Step title='原文を変更したら再スキャンする'>
    OCR
    原文や原文の言語を変更した場合、原文を追加・削除した場合、ページ順を変更した場合は、用語集に**再スキャンが必要**と表示されます。用語一覧を使う前に**用語集を再スキャン**してください。
  </Step>
</Steps>

再スキャンすると、信頼度、出現回数、用例、最新スキャンでの検出状態が更新されます。既存の訳語と有効・無効の設定は維持されます。見つからなくなった用語も自動削除されず、**最新のスキャンでは未検出**と表示されるため、必要に応じて確認または削除できます。

<Note>
  **再スキャンが必要**は、OCR
  原文の変更によって用語集全体が古くなった状態です。**今回未検出**は、最新の完了済みスキャンで個別の用語が見つからなかった状態です。
</Note>

OCR 中に停止すると、すでにコミットされた OCR 結果は残りますが、用語集は更新されません。ローカルの用語抽出中に停止した場合やスキャンが失敗した場合も、途中の用語は保存されません。プロジェクトを閉じる、または切り替える操作でも、実行中のスキャンに停止が要求されます。

ローカルの用語抽出中に OCR 原文が変更された場合、そのスキャン結果は破棄され、再スキャンが必要になります。

## 用語を確認・編集する

検索では原語と訳語の両方が対象になります。カテゴリフィルターと、**翻訳済み**、**未翻訳**、**無効**、**今回未検出**の状態フィルターを組み合わせられます。

各項目では、次の情報を確認できます。

- 原語、訳語、カテゴリ
- 検出時の信頼度（利用できる場合）
- 出現回数、原語と訳語の作成元
- プロジェクト内の短い用例
- 最新のスキャンで検出されたかどうか

行内で原語、訳語、カテゴリを編集できます。項目ごとのスイッチで、その用語を有効または無効にします。**用語集の操作**から**用語を追加**を選んで手動登録することもできます。各行から 1 件を削除するほか、複数項目を選択してまとめて削除できます。**表示中の用語を選択**は、現在の検索条件とフィルターに一致する項目を選択します。

パネル上部のスイッチは、通常の本文翻訳に対してプロジェクト用語集全体を有効または無効にします。本文翻訳へ適用されるのは、用語集が有効で、項目も有効になっており、空でない訳語が設定された用語です。

## 用語を自動翻訳する

処理設定で現在選択している翻訳モデルを使って、未翻訳の用語に訳語を追加できます。

- 項目を選び、**選択項目を翻訳**を選ぶと、選択項目のうち有効かつ未翻訳の用語だけを翻訳します。
- **用語集の操作 → 未翻訳を自動翻訳**を選ぶと、プロジェクト内の有効かつ未翻訳の全項目を翻訳します。

用語集には翻訳先の言語が必要です。選択中のプロバイダーは、その言語とシステムプロンプトの両方に対応している必要があります。条件を満たさない場合、エラーが表示され、用語集は変更されません。返された訳語は最後にまとめて 1 回だけ保存されます。プロバイダーでエラーが発生した場合、またはその保存が始まる前に停止要求が検知された場合、項目は変更されません。保存が始まった後は取り消せません。

自動翻訳の結果は、本文翻訳に使う前に確認してください。生成された訳語は行内で修正できます。

## 本文翻訳を開始する

用語集のスキャンと用語の自動翻訳は準備作業です。用語を確認したら、次の手順で本文を翻訳します。

<Steps>
  <Step title='用語集を有効にする'>
    パネル上部の**用語集を有効にする**をオンにし、使用する各項目も有効にします。
  </Step>
  <Step title='本文翻訳を明示的に開始する'>
    通常の処理セレクターまたは**処理**メニューから翻訳を実行します。範囲と段階の動作は[ページを処理する](/ja/guides/processing)を参照してください。
  </Step>
  <Step title='ページを確認する'>
    訳文全体と合わせて、固有名詞と用語の使われ方を確認します。詳しくは[テキストとレイヤーを確認する](/ja/guides/review)を参照してください。
  </Step>
</Steps>

ジョブの開始時に、有効で空でない訳語を持つ全項目が 1 つのスナップショットとして固定されます。ページ処理中に用語集を編集しても、実行中のジョブでは同じスナップショットが使われます。後から加えた変更を反映するには、新しい翻訳ジョブを開始してください。

<Warning>
  DeepL、Google Cloud Translation、Caiyun
  は、用語集が有効で訳語付きの有効項目がある状態では本文翻訳を実行できません。これらのプロバイダーは、用語集に必要なシステムプロンプトを受け取れません。Koharu
  は機能上の制限をエラーとして表示し、用語集を外して処理を続行することはありません。[プロバイダー設定](/ja/models/providers)でシステムプロンプト対応のプロバイダーを選ぶか、用語を使わずに翻訳する場合は**用語集を有効にする**をオフにしてください。
</Warning>

## JSON をインポート・エクスポートする

**用語集の操作 → 用語集をエクスポート**を選ぶと、ブラウザーから JSON ファイルをダウンロードします。ファイルには原文と翻訳先の言語、および各項目の原語、訳語、カテゴリ、有効状態が含まれます。信頼度、用例、出現回数、プロジェクトのリビジョンは書き出されません。

別のプロジェクトで再利用するには、そのプロジェクトの用語集を開いて**用語集をインポート**を選びます。Koharu はブラウザーで選択した JSON ファイルを読み取り、追加、競合、同一項目の件数をプレビューに表示します。

競合時の処理を選択します。

- **既存を保持**：開いているプロジェクト側の値を残します。
- **既存を置換**：競合する用語にインポート側の値を使います。

原文言語と翻訳先言語はそれぞれ、プロジェクト用語集とインポートファイルの両方に空でない値があり、その値が異なる場合に限り、差異が表示され、明示的な確認が必要です。プロジェクト用語集に対応する言語情報がない場合は、ファイルの値が設定されます。インポートした用語が翻訳されたり、別の言語へ変換されたりすることはありません。

用語集は各プロジェクトが個別に所有します。ライブ共有やグローバル用語集はありません。別のプロジェクトへ渡す場合は、JSON のエクスポートとインポートを明示的に行います。プロジェクトの保存とバックアップについては[プロジェクトと読み込み](/ja/guides/projects)を参照してください。

## 編集中にプロジェクトが更新された場合

用語集の編集は、現在のプロジェクトリビジョンに対して適用されます。先に別の操作でプロジェクトが更新されると、Koharu は競合を通知して用語集を最新の状態へ更新し、古い編集内容を自動で再実行しません。更新後の項目を確認し、必要ならもう一度編集してください。プロジェクトを切り替えると、選択項目と処理中のインポート状態が消去され、前のプロジェクトの結果は新しいプロジェクトに表示されません。
