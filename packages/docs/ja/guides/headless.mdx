`--headless` なしで起動すると、Koharu はデスクトップエディターを開きます。`koharu --headless` はデスクトップの CEF ウィンドウを作らず、既存のエディター Web UI をシステムのブラウザー向けに配信します。

## ブラウザーでエディターを開く

<Tabs>
  <Tab title="macOS と Linux">
    ```bash
    koharu --port 4000 --headless
    ```
  </Tab>
  <Tab title="Windows">
    ```powershell
    koharu.exe --port 4000 --headless
    ```
  </Tab>
</Tabs>

ターミナルに表示された URL を開きます。既定値は `http://127.0.0.1:4000/` です。エディターを使っている間はプロセスを動かしたままにし、終了するときは `Ctrl+C` を押します。

ブラウザーの UI は同じアプリで、ブラウザー向けトランスポート経由で接続します。ヘッドレスモードに MCP や OpenAPI はありません。

<Note>
  キャンバスにはブラウザーの WebGPU が必要です。動作するグラフィックスドライバー付きの新しい
  Chrome または Firefox を使ってください。[ハードウェアとランタイム](/ja/hardware)も参照してください。
</Note>

## フラグ

| フラグ       | 効果                                           |
| ------------ | ---------------------------------------------- |
| `--headless` | HTTP でエディターを配信し、デスクトップウィンドウを開かない |
| `--port`     | 待ち受けるポート。既定値は `4000`              |
| `--host`     | 待ち受けるアドレス。既定値は `127.0.0.1`       |
| `--download` | ランタイムとモデルを準備して終了する           |
| `--cpu`      | GPU があっても CPU 推論を使う                  |
| `--debug`    | デバッグ用のコンソール出力を有効にする         |

ホストの既定値は `127.0.0.1`、ポートの既定値は `4000` です。リリースビルドで `--port` を省略し、そのポートが使用中のときは、空いているポートまで番号を上げてバインドします。`--port` を指定した場合はそのポートだけを使います。

`--download` はランタイムとモデルを準備したあと、エディターを起動せずに終了します。`--cpu` は CPU 推論を選びます。

## ネットワークアクセス

localhost へのリクエストに認証はありません。`--host 0.0.0.0` へのバインドは意図的で、保護されていません。そのポートに到達できる人はエディターを使えます。ループバック以外へ公開するときは、ファイアウォール、リバースプロキシ、または独自の認証を置いてください。
