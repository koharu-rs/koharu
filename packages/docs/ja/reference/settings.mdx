---
title: '設定'
description: '外観、モデル、プロバイダー、翻訳、フォント、サイトへのログインの設定を探します。'
---

**ファイル → 設定**、ページ一覧の設定ボタン、またはスタート画面の設定ボタンから開きます。変更は少し待つと自動で保存されます。**エディターに戻る**で編集に戻ります。

## 外観

**ライト**、**ダーク**、**システム**のテーマと、インターフェースの言語を選びます。これらはページの描画や翻訳の対象言語には影響しません。

## パイプライン

工程ごとにモデルを選びます。検出エンジン、認識エンジン、インペイントエンジン、翻訳エンジンの 4 つです。検出エンジンにはテキスト、擬音、吹き出し、コマのしきい値があり、インペイントエンジンには生成系モデルが従うプロンプト、翻訳エンジンには**ビジョン**、**推論**、対象言語、**追加の指示**があります。処理セレクターでも翻訳のモデルと対象言語を設定できます。[画像処理モデル](/ja/models/vision)と[翻訳の設定](/ja/models/translation)を参照してください。

## プロバイダー

[翻訳プロバイダー](/ja/models/providers)に挙げた接続について、API キーの入力、サブスクリプションへのサインイン、ベース URL の設定を行います。キーとサインイン情報はこのデバイスに暗号化して保存され、ベース URL は `config.toml` に保存されます。

## レンダラー

新しいプロジェクトが最初に使う書体を、文字体系別に設定します。近い書体は見出しの下にまとめて並びます（明朝系：明朝体、仿宋体、楷書体、教科書体など）。書体ごとにフォントと太さのメニューと斜体の切り替えがあり、メニューの最初の**既定**はアンチックのフォントを使います。変更しない限り、ラテン文字にはスキャンレーショングループのフォントガイドが文字の種類ごとに使うフォントが使われます。アンチックは CCWildWords、明朝体のナレーションは CCVictorySpeechLower、ゴシック体の叫びは CreativeBlock BB、丸ゴシック体のモノローグは Anime Ace 3 BB の斜体、手書きは Ashcan BB、筆書体は Ninjutsu BB、デザイン書体は Voice Activated BB、ポップ体は Komika Slick、古印体と装飾書体は ManEater BB です。これらのフォントにないキリル文字とギリシャ文字は CCWildWords の斜体か太字の斜体、中国語と日本語にはそれぞれの書体の同梱フォントが使われます。空欄の値はアンチックの値を使います。**既定に戻す**で、すべての用字系の書体が Koharu の既定に戻ります。その後はプロジェクトが独自の書体を持ち、**ファイル → 既定の書体を使用**でこれらをもう一度適用できます。テキスト自身のフォント、太さ、斜体はそれより優先されます。

## ギャラリー

[ギャラリー](/ja/guides/gallery)が読むサイトの一覧です。**ログイン**はサイト自身のログインページを別ウィンドウで開きます。ウィンドウを閉じると、サイトが伝えるアカウントが行に表示され、**サインアウト**でそのサイトのログインを消去します。アカウントのないサイトには**アカウント不要**と表示されます。

## 設定ファイル

設定は `~/.koharu/config.toml` に、コンポーネントごとのテーブルとして保存されます。ローカルモデルの量子化など、画面のないオプションはこのファイルを直接編集して設定します。書かれていないキーは既定値を使い、アプリは変更したキーだけを書き込みます。型の違う値や、もう存在しないモデルなど、読み取れない値は既定値に戻ります。TOML として正しくないファイルはエラーになります。認証情報はここに書かず、**設定 → プロバイダー**で保存してください。

```toml
[pipeline.translator]
model = "koharu/index-translate-9b:Q8_0"
target = "ja"
instructions = "敬称（さん、先輩など）はそのまま残してください。"

[providers.openai-compatible]
base_url = "https://example.com/v1"
context_window = 32768
```

### `[pipeline.detector]`

<ResponseField name='model' type='string' default='koharu-layout-highres'>
  検出モデル。
</ResponseField>
<ResponseField name='text, onomatopoeia, bubble, panel' type='number'>
  各種類の検出を残す最低の信頼度で、0 から 1 の値です。書かなければモデル自身の値です。
</ResponseField>

### `[pipeline.recognizer]`

<ResponseField name='model' type='string' default='hayai-ocr'>
  認識モデル。`hayai-ocr`、`manga-ocr-ar`、`baberu-ocr` のいずれかです。
</ResponseField>

### `[pipeline.inpainter]`

<ResponseField name='model' type='string' default='lama'>
  ページと**削除**のストロークを処理するモデル。`lama`、`flux3-klein`、`qwen-image` のいずれかです。
</ResponseField>
<ResponseField name='fill' type='string' default='flux3-klein'>
  **生成塗りつぶし**が最後に使ったモデルで、次回もこれを選びます。
</ResponseField>
<ResponseField name='prompt' type='string'>
  実行が独自のプロンプトを持たないときに `flux3-klein` と `qwen-image`
  へ送る指示。既定では、セリフ、擬音、手書きのメモを含むすべての文字を消し、吹き出しを空にして、それ以外はそのまま保つよう求めます。
</ResponseField>

### `[pipeline.translator]`

<ResponseField name='model' type='string' default='koharu/index-translate-9b'>
  モデルピッカーと同じ `provider/model`
  形式の参照。ローカルモデルはコロンの後に量子化を指定できます（例:
  `koharu/index-translate-9b:Q8_0`）。
</ResponseField>
<ResponseField name='target' type='string' default='en'>
  対象言語の BCP 47 タグ。例: `ja`、`pt-BR`、`zh-Hant`。
</ResponseField>
<ResponseField name='instructions' type='string'>
  **追加の指示**。Koharu 自身のプロンプトの後に、書いたとおりに加えられます。
</ResponseField>
<ResponseField name='vision' type='boolean' default={false}>
  各ページの画像をテキストと一緒にモデルへ送るかどうか。
</ResponseField>
<ResponseField name='reasoning' type='string'>
  `off`、またはレベル（`minimal`、`low`、`medium`、`high`、`xhigh`、`max`）。書かなければモデル自身の設定です。
</ResponseField>

### `[providers.<provider>]`

サーバーのアドレスを持つプロバイダーごとに 1 つのテーブルです: `ollama`、`lmstudio`、`openai-compatible`。

<ResponseField name='base_url' type='string'>
  サーバーのアドレス。書かなければ Ollama と LM Studio の通常のローカルアドレスです。OpenAI
  互換サーバーのアドレスは、OpenAI の `/v1` に当たる部分で終わります。
</ResponseField>
<ResponseField name='context_window' type='integer'>
  OpenAI 互換サーバーがモデルを動かしているコンテキスト長（トークン数）。llama.cpp の `--ctx-size`
  など。[翻訳のしくみ](/ja/how-it-works/translation#会話が保持するもの)を参照してください。
</ResponseField>

### `[renderer]`

<ResponseField name='styles' type='table'>
  新しいプロジェクトが最初に使う、書体ごと、文字体系ごとのフォント。`styles.<書体>.<文字体系>` に `family`、`weight`、`italic`
  を書きます。例: `styles.rounded.Latn.italic = true`。書体は `antique`、`mincho`、`fangsong`、`kaisho`、`textbook`、`gothic`、`rounded`、`handwriting`、`brush`、`gyosho`、`gyokai`、`sosho`、`reisho`、`tensho`、`kointai`、`weibei`、`design`、`pop`、
  `decorative`、文字体系は `Latn`、`Hans`、`Hant`、`Jpan` などの ISO 15924 コードです。1 つでも変更すると、表全体が書き込まれます。
</ResponseField>

### `[agent]`

<ResponseField name='model' type='string'>
  エージェントのモデル。`provider/model` 形式の参照です。選ぶまでは書かれません。
</ResponseField>
<ResponseField name='reasoning' type='string'>
  翻訳の `reasoning` と同じ形式で、エージェント用です。
</ResponseField>

プロジェクトとダウンロードの保存先は[データの保存場所](/ja/reference/data)を参照してください。
