## 対応形式

| 用途                 | 形式                                |
| -------------------- | ----------------------------------- |
| 読み込み             | PNG、JPEG、WebP、CBZ、ZIP、RAR、PDF |
| 統合画像             | PNG                                 |
| レイヤー付き交換形式 | PSD                                 |
| 作業プロジェクト     | `.khrproj` ディレクトリ             |

## プロジェクト

`Documents/Koharu/<project-name>.khrproj/` に保存します。交互に書き込む状態ファイルと、元画像、生成画像、手動ラスター編集用の内容アドレス方式の blob を含みます。

<Warning>
  開いているプロジェクトの内部ファイルを変更しないでください。プロジェクト一覧から削除すると、ディレクトリ全体が完全に削除されます。
</Warning>

## 設定と資格情報

秘密でない型付き設定は `~/.koharu/config.toml` にあり、パイプライン、プロバイダー、組版、Agent が各セクションを担当します。未指定の設定には既定値を使います。不正な手動編集は初期化失敗の原因になるため、設定画面を使ってください。

資格情報は OS の安全な資格情報サービスへ保存します。プロジェクトのバックアップにキーや Agent のアカウントセッションは含まれません。

## ランタイムとモデルのキャッシュ

OS キャッシュ内の `<cache>/koharu/packages/` に保存します。Koharu を閉じた状態で削除すると、必要なパッケージを再取得します。

プロセスがネイティブライブラリを読み込んでいる可能性がある間は削除しないでください。

## バックアップ

<Steps>
  <Step title='プロジェクトを閉じる'>作業を終えてからファイルをコピーします。</Step>
  <Step title='ディレクトリ全体をコピーする'>
    状態ファイルと blob を一緒に保存します。PSD はプロジェクトのバックアップではありません。
  </Step>
  <Step title='設定を別に保存する'>
    必要なら `config.toml` をコピーします。復元先の端末では Koharu から資格情報を設定し直します。
  </Step>
</Steps>
