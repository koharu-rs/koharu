---
title: 'キーボードショートカット'
description: 'ツール、移動、選択、undo の既定操作です。'
icon: 'keyboard'
---

プロジェクトを開いていて、入力欄や編集可能なテキスト領域にフォーカスがないときに適用されます。

## ツール

| ツール               | キー |
| -------------------- | ---- |
| 選択                 | `V`  |
| テキスト             | `T`  |
| ブラシ               | `B`  |
| 消しゴム             | `E`  |
| スポイト             | `I`  |
| 除去                 | `J`  |
| パン                 | `H`  |
| ウィンドウに合わせる | `0`  |

**設定 → ショートカット**で変更できます。

## 移動

| 操作                               | ジェスチャー                 |
| ---------------------------------- | ---------------------------- |
| 一時的にパン                       | `Space` を押しながらドラッグ |
| ジェスチャーのキャンセル・選択解除 | `Escape`                     |
| ページ全体を表示                   | 既定は `0`                   |

Space を離すと前のツールに戻ります。Koharu からフォーカスを移すと、未完了のキャンバス操作はキャンセルされます。

## 編集

| 操作                               | Windows / Linux             | macOS                       |
| ---------------------------------- | --------------------------- | --------------------------- |
| 元に戻す                           | `Ctrl+Z`                    | `Command+Z`                 |
| やり直す                           | `Ctrl+Shift+Z`              | `Command+Shift+Z`           |
| ページの編集可能な全レイヤーを選択 | `Ctrl+A`                    | `Command+A`                 |
| 選択レイヤーを削除                 | `Delete` または `Backspace` | `Delete` または `Backspace` |

<Tip>
  各ツールに異なる文字を割り当ててください。重複すると、ツールバー順で最初に一致した操作が優先されます。
</Tip>

ショートカットは UI の操作にだけ影響し、書き出したページには影響しません。
