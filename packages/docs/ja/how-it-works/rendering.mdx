Koharu のレンダラーは 1 つです。キャンバス、PNG、PSD、CBZ、PDF の書き出し、ページのサムネイル、**削除**のストロークが読むページは、すべて GPU 上の vello で同じペインターを通して描かれます。そのため書き出しはエディターの表示と一致し、Koharu はプロジェクトを開くだけでも動作する GPU を必要とします。

## 描くたびにテキストを組む

テキストの大きさ、改行位置、枠の中の位置は、ページを描くたびに求められ、ほかの場所では求められません。古くなる結果はどこにも保存されません。フォント、枠、単語を変えれば、次の描画でテキストが収め直されます。

再描画が速いのは、レイヤーの描画結果を、テキストやフォントなど依存するものごとに保持しているからです。編集後の描画では、編集が触れなかったレイヤーをすべて再利用します。ビューはページの見えている部分だけを、そのズームに合った詳細度で描きます。

ページや読み込んだ画像は、1 辺 32,768 ピクセル、合計 268,435,456 ピクセルまで扱えます。PSD の書き出しは、Photoshop 自身の上限である 1 辺 30,000 ピクセルまでです。

## 行を組む

- **シェーピング。** テキストはフォント、文字体系、方向が同じ連なりに分けられ、それぞれ HarfBuzz の Rust 移植である HarfRust で一度だけシェーピングされます。
- **改行。** 改行は Unicode の改行規則に従い、1 行ずつではなくテキスト全体を見て決めます。枠の中で中央揃えのテキストは、行の長さを揃えます。中国語は jieba で単語を見つけ、単語の間で改行します。
- **吹き出しの形。** 吹き出しの形をした枠では、枠の高さに入るすべての行数を試し、最もよく収まるものを選びます。Photoshop は形の中で各行をそれぞれの幅の中央に置きますが、Koharu はすべての行を 1 本の軸に中央揃えするため、いびつな吹き出しでも行が輪郭に沿ってぶれません。
- **右から左。** アラビア語やヘブライ語の行は、Unicode の双方向アルゴリズムが示す順に並び、右から始まります。

## 縦書き

縦書きの列は、W3C の日本語・中国語組版処理の要件と CSS の縦書きに従い、右から左へ並びます。

| 文字                                     | 列の中では                                                                   |
| ---------------------------------------- | ---------------------------------------------------------------------------- |
| ラテン文字と 3 桁以上の数字              | 時計回りに 90 度回転します                                                   |
| ラテン文字の単語の外にある 1〜2 桁の数字 | CSS の `text-combine-upright: digits 2` と同じく、1 マスに縦中横で収まります |
| `!` と `?`                               | 全角になり、2〜3 個続くと 1 マスに正立して収まります                         |
| `、` と `。`                             | マスの隅に縦書き用の字形で置かれます。中国語では中央に置かれます             |
| `〜`、`…`、`—`、`・`、`：`               | 列の中央に置かれます。フォントに縦書き用の字形がなければ回転します           |
| 行頭の `「` や `『`                      | その前の半角分の空きなしに、括弧のインクから行が始まります                   |

句読点、小書きの仮名、ラテン文字の並びは、選んだフォントで確認してください。見た目は、フォントの縦書き用字形とメトリクスにも左右されます。

## ルビ

ルビは親文字の半分の大きさで、横書きでは行の上、縦書きでは列の右に付きます。W3C の簡単なルビの規則と同じく、ルビと親文字の短いほうを、両端に半分ずつの空きを取って長いほうの長さに広げるため、両者は中央で揃い、ルビが隣の文字にかかることはありません。親文字は行をまたいで分割されず、ルビのある行はルビに必要なだけ行間を空けます。

## どのフォントでも太字と斜体

太字や斜体の書体を持つフォントは、その書体を使います。持たないフォントでは Koharu がそれを疑似的に作り、文字ツールバーのツールチップに**疑似太字**または**疑似斜体**と表示されます。

- **疑似太字**は、CC Wild Words 自身の太字と同じく、各字形を左右それぞれ 0.02 em 太くし、字送りを 0.04 em 広げます。全角の文字は、CJK フォントの太字と同じく幅を保ちます。すでに太字の書体は、それ以上太くなりません。
- **疑似斜体**は、正立したテキストを CSS の既定の斜体角度である 14° だけ右へ傾けます。縦書きの列では、正立した各文字が自分の中心を軸に傾くため、列の中心線から外れません。

PSD の書き出しでは、これらを Photoshop の疑似太字と疑似斜体として書き込みます。

  <Step title='記号と絵文字のフォント' />

言語の指定がないテキストは、仮名があれば日本語、ハングルがあれば韓国語、漢字だけなら簡体字中国語として扱われるため、中国語が日本語のシステムフォントで描かれることはありません。記号、数字、空白は隣のテキストのフォントを使うため、CJK の文の句読点はその CJK フォントから取られます。1 つの文字が 2 つのフォントに分かれることはありません。

フォント一覧には、1 つのバージョンに固定された Koharu のフォントデータセットのファミリーも含まれます。テキストが必要とする書体は組むときにダウンロードされ、描画はそれを待ちます。ダウンロードに失敗したファミリーは、順に代替フォントへ進みます。
