翻訳は、選んだモデルとの会話です。ページ順に 1 ページ 1 ターンで進みます。各ページはそれより前のページを踏まえて翻訳されるため、名前、口調、繰り返し出る用語がページをまたいで引き継がれます。

## プロジェクトごとに 1 つの会話

会話は開いているプロジェクトに属し、プロジェクトを開いている間だけ続きます。ページを翻訳するとそのターンが加わり、一部のテキストブロックの翻訳も同じ会話の 1 ターンです。モデル、対象言語、**追加の指示**を変えると、履歴が古い設定で書かれているため、新しい会話になります。

前のページが文脈になるため、章は最初のページから翻訳してください。後のページだけを翻訳すると、会話がすでに持っているターンしか参照できません。

## モデルが受け取るもの

Koharu のシステムプロンプトは、Index-Translate の構造化データ向けの指示を英語にしたもので、対象言語を英語名で示します。

```text
Translate the manga text in each message into English. Each message is a page's texts as a JSON object, numbered in reading order: translate only the values, and never alter the structure or the keys. Output only the translated JSON, without any explanation.
```

**追加の指示**は、どの言語でも、書いたとおりにその後へ続きます。回答は JSON として読み戻されるため、プロンプト自体は変えられません。

各ページのターンは、ロックされていないテキストを読み順に、番号をキーとして並べたものです。

```json
{
  "1": "おい、待てよ！",
  "2": "あいつ、どこへ行った…？"
}
```

テキストが 10 個以上あると、キーは `01` から `12` のように 2 桁になり、読み順どおりに並びます。回答はすべてのキーを、それ以外のキーなしで返す必要があり、その形に従わせます。**ビジョン**がオンなら、テキストの前に長辺 1,280 ピクセルのページのスキャンが送られます。画像を読めないモデルには送られません。

## 会話が保持するもの

履歴には各ページのテキストとその回答が残りますが、画像やモデルの推論は残りません。そのため履歴はテキストの分しか増えず、ローカルモデルはターンをまたいで再利用できます。モデルのコンテキストウィンドウに近づくと、古いページはモデル自身が書く要約にまとめられ、会話はそこから続きます。翻訳専用のモデルは要約できないため、古いページは代わりに捨てられます。

**OpenAI 互換**として接続したサーバーは自分のコンテキストウィンドウを伝えないため、**設定 → プロバイダー**で**コンテキスト長**を設定してください。設定しないと、サーバーがプロンプトを切り詰めるまで履歴が増え続けます。

## ページを聞き直すとき

Koharu が使える回答を得られなかったページは、理由に応じて聞き直されます。

| 理由                                                             | 聞き直し方                                                         |
| ---------------------------------------------------------------- | ------------------------------------------------------------------ |
| 回答が壊れている、またはテキストが欠けている                     | 1 回。何が違うかを伝えます                                         |
| テキストが違うのに、回答が前のページの回答を写している           | 1 回。写した元の履歴を除きます                                     |
| プロバイダーが内容を理由にページや回答をブロックした             | 1 回。ブロックの原因かもしれない履歴を除きます                     |
| ページがモデルのコンテキストウィンドウに収まらない               | 1 回。履歴の古い半分を捨てます                                     |
| 同じことを繰り返し続けるなどして、ローカルモデルの回答が途切れた | 2 回。毎回ランダム性を上げます。そうしないと同じ回答になるからです |

それでも回答が得られないページや翻訳が空のページは、未翻訳のまま残って履歴にも入らず、[実行は続きます](/ja/guides/processing#進捗と停止)。ホスト型モデルでは、再試行のたびにリクエストが 1 回増えます。プロバイダーが過負荷のときやレート制限をかけたときは、実行を終える前に、約 2 分半、またはプロバイダーが求める間、最大 9 回までリクエストを送り直します。

## そのまま残るテキスト

著作権表記や `!?` のように、モデルがそのまま返したテキストは、すでに対象言語の文字で書かれています。元の文字が残り、クリーンアップは隠れ、翻訳は付きません。

## ビジョンと推論

**ビジョン**は各ページをモデルに見せ、**推論**は回答の前にモデルに考えさせます。Index-Translate 9B で 16 ページを試した Koharu 自身のテストでは、どちらも翻訳は良くならず、時間だけが増えました。そのため、ビジョンはオフ、推論はモデル自身のレベルが既定です。設定したレベルを受け付けないモデル（常に推論するモデルに**オフ**を指定した場合など）では、実行が止まり、その設定名が示されます。

## より良い翻訳のために

- 先に OCR を直します。モデルが翻訳するのはスキャンではなく原文です。
- 名前、用語、敬称、口調は**追加の指示**に書き、数ページで試します。
- 章の最初から翻訳し、後のページが前のページを参照できるようにします。
- 仕上げた翻訳はロックします。再実行で書き換えられず、そのページのターンからも外れます。
