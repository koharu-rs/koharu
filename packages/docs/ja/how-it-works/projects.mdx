プロジェクトは、ページを順に保持する 1 つの `.khr` ファイルです。各ページはスキャンとレイヤーのツリーから成ります。通常のレイヤーは Photoshop に倣い、マンガのページの部品は CLIP STUDIO PAINT のコマと吹き出しに倣います。

## ページのレイヤー

検出はツリーを読み順に作るため、ページは先頭から順にこう読めます。

| レイヤー         | 内容                                                                                                                                                   |
| ---------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 背景             | 読み込んだスキャン。バイト単位でそのまま保持され、すべての下に描かれます。何も上に描き込まれないため、上にあるものを隠すか削除すると元の画像が見えます |
| コマ             | コマの輪郭。その中で読まれる吹き出しとテキストを保持します。何も切り抜かないため、枠線をまたぐ吹き出しも読まれるコマに残ります                         |
| 吹き出し         | 吹き出しの輪郭。その中のテキストを保持します。線と塗りはスキャンの一部なので、輪郭そのものは描かれません                                               |
| テキストブロック | ページ上の 1 つのテキスト。吹き出しの中か、コマやページの上に単独で置かれます。下を参照してください                                                    |
| 通常の種類       | グループ、画像、ラスター、シェイプ、テキスト、マスク。Photoshop と同じく、表示、ロック、不透明度、描画モードを持ちます                                 |

ツリーの順序が読み順です。**ストーリー**はこの順にテキストを並べます。**レイヤー**は Photoshop のレイヤーパネルと同じく最前面から並べるため、最後に読まれるテキストが一番上の行になります。**レイヤー**で行をドラッグすると、読み順も移動します。

## テキストブロック

テキストブロックは 1 つのテキストの 4 つの部分をまとめて保持するため、どれかを直しても残りを作り直す必要がありません。

| 部分           | 書き込むもの                         | 描画                                             |
| -------------- | ------------------------------------ | ------------------------------------------------ |
| 原文           | 検出の枠と OCR の文字列              | されません。モデルが読み、あなたが直すものです   |
| 翻訳           | 翻訳、またはあなたの入力             | されます。枠の中、クリーンアップの上に描かれます |
| マスク         | 検出、またはあなたの描画             | されません。クリーンアップが見える範囲を決めます |
| クリーンアップ | インペイント、**削除**、あなたの描画 | マスクの内側だけ、翻訳の下に描かれます           |

クリーンアップは、Photoshop のレイヤーマスク付きの塗りつぶしレイヤーのように働きます。マスクを塗れば、再実行なしでクリーンアップの見える範囲がすぐに変わります。そのため各部分は次のようにふるまいます。

- テキストブロックを削除するとクリーンアップも消え、元の文字が再び見えます。
- 翻訳のないブロックもクリーンアップは表示されるため、その範囲は新しい文字のためにきれいなまま残ります。
- 各テキストは自分の枠に自分の翻訳を持ちます。文字がある枠から別の枠へ流れ込むことはありません。

**テキスト**レイヤーは自分で入れる文字で、原文、マスク、クリーンアップを持ちません。

## すべての変更は編集です

エディター、パイプラインの実行、エージェントは、どれも同じ編集でプロジェクトを変更します。編集は全体が適用されるか、まったく適用されないかのどちらかで、それぞれが 1 つの取り消しステップです。何も変えない編集はステップを追加しません。

値はモデルかあなたかを問わず、最後に書いたものが優先され、戻すには取り消しを使います。唯一の守りはロックで、ロックしたレイヤーにはどのパイプライン工程も書き込みません。

**表示 → ヒストリー**は、開いた時点の状態に続けてステップを並べ、Photoshop のヒストリーパネルと同じく、どのステップへも一度で戻ったり進んだりできます。保持するのは直近 20 ステップ（Photoshop の既定値）で、Photoshop でドキュメントを閉じると状態が消えるのと同じく、プロジェクトを閉じると消えます。

## プロジェクトの保存方法

- **1 つのファイル。** プロジェクトは `.khr` 拡張子の SQLite データベースで、CLIP STUDIO PAINT の作品が 1 つのファイルであるように、読み込んだ画像も中に含みます。元のファイルを移動や削除してもプロジェクトには影響しません。
- **保存操作なし。** 各編集は適用と同時に書き込まれるため、未保存の変更はありません。
- **タイル。** ラスターのピクセルは 64 × 64 のタイルに分けて個別に圧縮され、ピクセルを含むタイルだけが保存されます。クリーンアップは覆う範囲だけを保存します。
- **1 つのウィンドウ。** 開いているプロジェクトはロックされるため、別のウィンドウや別の Koharu からは使用中になります。
- **開けないものは開かない。** 壊れたファイルや、プロジェクト形式が変わった新しい Koharu で書かれたファイルは開かず、ファイルは元のまま残ります。
