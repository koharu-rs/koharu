クリーンアップ、つまり**インペイント**工程は、各テキストの文字をスキャンから取り除きます。結果はテキストブロックのクリーンアップに入り、ブロックのマスクの内側だけ、翻訳の下に表示されます。スキャン自体は変わりません。

## モデルより先に塗りつぶす

多くの文字は白い紙やなめらかなグラデーションの上にあり、塗りつぶしなら正確に、すぐに再現できます。そこでモデルを使うと質感や色味が加わることがあるため、Koharu は必要な場所にだけモデルを使います。

Koharu は文字ごとに、マスクのすぐ外側、吹き出しやコマの内側にある、マスクされていないピクセルの輪を読み、その輪を再現できる最初の段階でマスクを埋めます。

| 段階           | 条件                                                                                                   | 埋め方                                     |
| -------------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| 単色           | 輪のすべてのピクセルが輪の中央値から 16 段階以内、または平均でそれだけ近く、大きく外れたピクセルがない | 中央値の色                                 |
| なめらかな背景 | 輪に合わせたグラデーションを差し引いた後で同じ条件を満たす                                             | OpenCV から移植した Telea の Fast Marching |
| モデル         | それ以外: 吹き出しの線をまたぐ文字、接する線や絵、トーン、判断するには小さすぎる輪                     | インペイントモデル                         |

周りが単色でない文字は、マスクの離れた断片ごとに判断し直します。検出は別の紙の上や吹き出しの線の上にある断片をマスクすることがあるからです。吹き出しの輪郭の外側の部分など、断片の紙で再現できないところだけがモデルに回ります。

## モデルの描き直し方

モデルはページ本来の縮尺のウィンドウで作業します。各ウィンドウは、文字全体とその周囲 256 ピクセルの文脈を含み、合わせて約 1 メガピクセルに収まる限り重なるウィンドウと結合され、2 つのコマにまたがることはありません。ページ全体をモデルに合わせて縮小すると文字が残り、大きなウィンドウを同じように縮小すると字形の形をした跡が残りました。ページ本来の縮尺なら、どちらも起きません。

各文字が描き直されるのは 1 つのウィンドウだけで、モデルには、そのウィンドウで描き直すものだけでなく、ウィンドウ内のすべての文字がマスクされた状態で見えます。

<Tabs>
  <Tab title='LaMa'>
    マンガ向けに追加学習した LaMa
    は、マスクの下を描き直し、プロンプトを使いません。マスクされたピクセルだけが残るため、結果が文字の外へはみ出すことはありません。
  </Tab>
  <Tab title='FLUX.3 Klein と Qwen-Image 2.1 Turbo'>
    これらは画像編集モデルです。どちらもインペイント用のモードを持たないため、ウィンドウを参照画像としてウィンドウ全体を描き直し、**設定
    →
    パイプライン**の**プロンプト**に従います。プロンプトは既定で、すべての文字を消し、それ以外はそのまま保つよう求めます。編集結果は色調がずれるため、残す前にマスクから離れた部分で元の色に合わせます。これがないと、塗りつぶしの境目が見えました。クリーンアップは描き直した結果を文字の周囲
    256 ピクセルまで保持してマスク越しに見せます。Photoshop
    が生成塗りつぶしの結果をレイヤーマスクの下に丸ごと残すのと同じで、マスクを広く塗るとより多く見えます。
  </Tab>
</Tabs>

## 削除ツールと生成塗りつぶし

**削除**のストロークは、それだけで 1 つの実行です。塗った範囲に、**設定 → パイプライン**のインペイントモデルでインペイントを行います。範囲はすべてモデルに回され、塗りつぶしの段階は使いません。Photoshop の削除ツールがすべてのレイヤーを参照するように、以前のクリーンアップ、描画、塗りつぶしを含めて描かれたままのページを、文字を除いて読みます。結果の上をもう一度塗ればそれを土台にでき、翻訳の文字が塗りつぶしに焼き込まれることはありません。

結果は**レイヤー**で選択中のラスターレイヤーかクリーンアップに描かれ、選択中のクリーンアップのマスクは塗った場所で開きます。何も選択していなければ、その範囲に限った新しいラスターレイヤーに描かれ、次のストロークのために選択されたままになります。

**生成塗りつぶし**は、**長方形選択**や**なげなわ**で指定した範囲に、プロンプトで求めたものを描きます。専用のモデル（ほかを選ばなければ FLUX.3 Klein）を持ち、Photoshop の生成塗りつぶしと同じく、次回のために選んだモデルを覚えます。設定で使っていない塗りつぶし用モデルは、最後の塗りつぶしから 5 分間読み込まれたままなので、続けて塗りつぶしても読み込み直しません。

## クリーンアップがうまくいかないとき

| 見えるもの                         | 対処                                                                                           |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| 字形の断片が残る                   | **削除**で上から塗るか、**ストーリー**のメニューからそのテキストに**インペイント**を実行します |
| 線画や枠線にかかったクリーンアップ | **レイヤー**でブロックのマスクを選んで消します。再実行は不要です                               |
| 良い結果が置き換えられた           | 再実行はクリーンアップを置き換えます。取り消してから、残したいテキストをロックします           |

設計と出典: [`koharu-pipeline` の README](https://github.com/koharu-rs/koharu/blob/main/crates/koharu-pipeline/README.md#3-inpainting)。
