---
title: '翻訳プロバイダーの接続'
description: 'ローカル GGUF、ホスト型サービス、互換モデルサーバーを設定します。'
---

モデル選択には、Koharu のローカルモデルと、接続済みの各プロバイダーのすべてのモデルが表示されます。モデルは `koharu/index-translate-9b` のように `プロバイダー/モデル` の形で名前が付きます。翻訳とエージェントは同じ一覧から選びます。エージェントにはツールを呼び出せるモデルだけが表示されます。

## 利用できる接続

| 接続               | プロバイダー                                                         | 接続方法                                   |
| ------------------ | -------------------------------------------------------------------- | ------------------------------------------ |
| ローカル推論       | llama.cpp でプロセス内実行する Koharu の GGUF モデル                 | 不要                                       |
| ホスト型 API       | OpenAI、Anthropic、Google Gemini、xAI、DeepSeek、MiniMax、OpenRouter | API キー                                   |
| サブスクリプション | ChatGPT、および SuperGrok または X Premium プランの Grok             | サインイン                                 |
| セルフホスト       | Ollama、LM Studio、OpenAI 互換サーバー 1 つ                          | ベース URL（サーバーが求める場合はキーも） |

Koharu のローカルモデルには、翻訳専用の Index-Translate（2B、9B、35B A3B プレビュー）と、Gemma 4、Qwen 3.5、Qwen 3.6、Qwen 3.8、LFM3 の各ファミリーの汎用モデル（一部は無検閲版あり）があります。既定の翻訳モデルは Index-Translate 9B です。各ローカルモデルは初めて実行するときに Hugging Face からダウンロードされます。

<Steps>
  <Step title='接続を保存する'>
    **設定 → プロバイダー**を開きます。プロバイダーの API キーを**認証情報**欄に入力すると、フォーカスが外れたときに保存されます。ChatGPT
    や Grok は**サインイン**を選び、ブラウザーで開いたページでサインインを完了します。求められたら Koharu
    に表示されたコードを入力します。

    Ollama、LM Studio、OpenAI 互換サーバーは**ベース URL**を入力します。Ollama と LM Studio
    は空欄なら通常のローカルアドレスを使い、LM Studio の場合は `http://localhost:1234` です。OpenAI
    互換サーバーには、OpenAI の `/v1` と同じ位置で終わるベース URL（例: `https://example.com/v1`）が必要です。あわせて**コンテキスト長**に、サーバーがモデルを動かすコンテキスト（llama.cpp
    の `--ctx-size` など）を入力します。翻訳は一貫性のために前のページを覚えており、いっぱいになる前に要約します。空欄だとページがたまり続け、サーバーがプロンプトを切り詰めて応答が失敗します。

  </Step>
  <Step title='モデルを選ぶ'>
    処理セレクターの**モデル**、または**設定 → パイプライン → 翻訳エンジン → モデル**を開きます。処理セレクターを開くと一覧が更新されます。キーのないプロバイダーや接続できないプロバイダーにはモデルが表示されません。
  </Step>
  <Step title='1 ページで試す'>
    原文を確認し、現在のページで翻訳を実行し、章全体を処理する前に結果を確認します。
  </Step>
</Steps>

## 認証情報とプライバシー

API キーとサインイン情報は `~/.koharu/secrets.age` に暗号化して保存され、その鍵は OS の資格情報ストアに保管されます。環境変数は読み込みません。ベース URL は `~/.koharu/config.toml` の `[providers]` セクションに保存されます。**サインアウト**はサブスクリプションのサインインを取り消して削除し、消しゴムボタンはキーを消去します。

ローカルモデルでは、ダウンロード後のページとテキストは自分のマシンから出ません。ホスト型プロバイダーは翻訳する各ページのテキストを受け取り、**ビジョン**が有効ならページ画像も受け取ります。その扱いは各社の保存条件に従います。検出と OCR がローカルでも、ホスト型の翻訳リクエストがローカルになるわけではありません。

<Warning>
  キーを追加の指示、テキストレイヤー、設定ファイルに書かないでください。認証情報は**設定 →
  プロバイダー**から保存します。
</Warning>
