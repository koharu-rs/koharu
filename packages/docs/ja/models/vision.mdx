**設定 → パイプライン**を開き、工程ごとにモデルを選びます。どのモデルも自分のマシンで動き、どれを選んでも[ワークフロー](/ja/guides/processing)は変わりません。

## 検出

RF-DETR のセグメンテーションモデルである **Koharu Layout HighRes** は、コマ、吹き出し、テキスト、擬音を見つけ、各テキストブロックのマスクと読み順を決めます。

テキスト、擬音、吹き出し、コマのしきい値は、各クラスに必要な確信度を決めます。空欄ならモデル自身の値を使います。しきい値を下げると不確かな領域も残り、誤検出が増えることがあります。代表的なページを何枚か比べてから変更し、そのページで検出をやり直してください。

## OCR

| モデル                                                                           | 読み取り対象                     |
| -------------------------------------------------------------------------------- | -------------------------------- |
| [Manga OCR AR](https://huggingface.co/muscgab/manga-ocr-ar-experimental)         | 日本語のマンガのテキスト（既定） |
| [Baberu OCR](https://huggingface.co/genshiai-daichi/baberu-ocr)                  | 日本語のマンガのテキスト         |
| [Hayai OCR](https://huggingface.co/JustANormalTinkerer/hayai-ocr-v2.7-supernova) | 日本語、中国語、韓国語、英語     |

Manga OCR AR のライセンスは CC BY-NC-SA 4.0 のため、既定のまま使う場合は非商用利用に限られます。各モデルのライセンスはモデルカードで確認してください。

<Note>
  OCR
  は検出されたテキストブロックを読み取ります。文字が抜けている場合は先に検出を確認してください。検出されなかったブロックは、認識モデルを替えても読み取れません。
</Note>

## インペイント

<Tabs>
  <Tab title="直接型">
    マンガ向けに追加学習した **LaMa** が既定です。通常の文字消しはここから始めます。
  </Tab>
  <Tab title="生成型">
    **FLUX.3 Klein** と **Qwen-Image 2.1 Turbo** は stable-diffusion.cpp で動き、**設定 → パイプライン**の**プロンプト**に従います。既定のプロンプトは、すべての文字を消してそれ以外はそのまま残すよう指示します。

    これらはより多くのダウンロード容量、メモリ、時間を必要とします。プロンプトには文字の除去を書き、訳文はテキストレイヤーで組版します。Qwen-Image 2.1 Turbo は Qwen Research License で、研究と評価の目的に限られます。

  </Tab>
</Tabs>

単色やなめらかな背景はモデルを使わずに埋めるため、モデルの違いが大きく出るのは線画やトーンの上の文字です。[画像修復](/ja/guides/cleanup)を参照してください。

## 初回の実行

重みはモデルを初めて読み込むときに、コミットを固定して Hugging Face からダウンロードされ、設定で別のモデルに切り替えるまで読み込まれたままです。初回の実行にはダウンロードと読み込みの時間が含まれるため、プロジェクトの既定を決めるときは、読み込み済みのモデルを同じページで比べてください。
