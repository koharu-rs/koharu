Typography is saved in the project. The canvas and every export draw the page the same way.

<Steps>
  <Step title="Choose a text frame">
    Translation places each block's text in its room in the balloon, or in its source's frame when it has no balloon, so resizing the frame reflows the text. To add text yourself, click with **Text** for point text or drag for a text box.
  </Step>
  <Step title="Choose fonts with the right coverage">
    The font list includes your installed fonts and the families of Koharu's font dataset, which download when a text first needs them. If a font lacks a glyph, Koharu tries the default families in **Settings → Typesetting**, then Arial, then the system's fallback for the text's script, then symbol and emoji fonts.

    Use fonts that cover the target script. A Latin display font alone is insufficient for Japanese or Chinese dialogue.

  </Step>
  <Step title="Fit and style the text">
    Select text blocks or text layers and set the font, color, size, weight, style, alignment, direction, and border in the **Type** section of **Properties**. Changes apply to every selected text.

    **Auto** size grows or shrinks a text box's text to the largest size the box holds, down to half its set size. New translations fit the same way, starting from the page's typical lettering size. Typing a size sets that size and shrinks the text only as far as it must to fit, again down to half.

  </Step>
  <Step title="Review at reading size">
    Check every page with the visibility and opacity you intend to export. Confirm each block has a translation: source text is never drawn.
  </Step>
</Steps>

## Vertical CJK text

Vertical columns run right to left. Latin letters and digits turn a quarter clockwise, `!` and `?` set full width, and a run of two or three of them sits upright in one cell. A translation is vertical only when its source is and the target is Japanese or Chinese; any other language runs horizontally, turned by its source's tilt.

Inspect punctuation, emphasis marks, Latin runs, and small kana individually. Font coverage, vertical metrics, and translation length still determine the quality of the result. Right-to-left scripts are laid out in their own direction.

<Tip>
  Use [PNG or CBZ for delivery and PSD for layered editing](/guides/export), and retain the Koharu
  project for future changes to text and fitting.
</Tip>
