title: 'Clean up source lettering'
description: 'Use inpainting and precise manual masks to remove lettering while preserving artwork.'

Inpainting reconstructs the artwork beneath source text. A precise removal region usually matters more than a larger model.

## Review automatic cleanup

Detection produces a removal mask. Inpainting uses it to create a cleanup layer; without a mask, the stage completes without inference. The pipeline skips inpainting on a page that already has a cleanup layer, so use **Remove** to inpaint again.

Inspect the result at normal reading size and high zoom. Look for glyph fragments, missed punctuation or furigana, erased bubble borders, repeated textures, smeared screentone, and changes outside the lettering.

## Repair a missed region

<Steps>
  <Step title='Paint a removal mask'>
    Choose **Remove**, set the brush diameter, and cover only the source marks that need
    reconstruction. Use controlled strokes and avoid neighboring line art. Cancel the gesture if the
    mask is wrong.
  </Step>
  <Step title='Let inpainting run'>
    Release the stroke. Koharu runs inpainting for that area at once and merges the result into the
    page's cleanup layer. Include enough of each glyph for the model to remove it without covering
    an entire bubble unnecessarily.
  </Step>
  <Step title='Touch up and inspect'>
    Use **Color picker**, **Brush**, and **Eraser** for small deterministic corrections. Check the
    result again at normal zoom.
  </Step>
</Steps>

Stopping a processing job does not turn its temporary removal mask into visible artwork.

## Choose a model

**LaMa** and **AOT** provide direct inpainting. **FLUX.2 Klein** and **RORem Mixed** are generative alternatives with prompt controls and larger resource requirements. See [vision and inpainting models](/en/models/vision).

<Warning>
  **Brush** strokes made while the cleanup layer is selected land on that layer, and a later
  **Remove** stroke merges into it. Clear the selection before painting to keep manual touch-ups on
  a separate Paint layer.
</Warning>
