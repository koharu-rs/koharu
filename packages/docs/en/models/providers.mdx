The translation picker combines local and hosted backends. A selection records the provider, model ID, optional local quantization, and vision-input setting.

## Available connections

| Connection          | Providers                                                                            |
| ------------------- | ------------------------------------------------------------------------------------ |
| Local inference     | GGUF models through llama.cpp                                                         |
| Hosted models       | Atlas Cloud, OpenAI, Gemini, Claude, Grok, MiniMax, DeepSeek, OpenRouter, OrcaRouter |
| Compatible servers  | LM Studio and OpenAI-compatible endpoints                                             |
| Machine translation | DeepL, Google Cloud Translation, Caiyun                                               |

Each provider owns its endpoint defaults, request mapping, and model discovery. Available models can change independently of these docs.

## OrcaRouter

[OrcaRouter](https://www.orcarouter.ai) is an OpenAI-compatible gateway. Its models use a
`vendor/model` namespace and are listed live, so the picker always reflects the models your own
OrcaRouter account can call.

There are two ways to connect, and either one is enough:

- **OrcaRouter - API** — paste an `sk-orca-…` key from
  [the OrcaRouter console](https://www.orcarouter.ai/console/authorized-apps).
- **Connect with OrcaRouter** — authorize Koharu in your browser. Koharu binds a temporary
  `127.0.0.1` listener, sends an OAuth 2.0 + PKCE (S256) request to the consent screen, and
  receives a key for your account. No client secret is involved and there is nothing to
  pre-register.

Both paths store the same kind of key in the operating system's secure credential service, and the
rest of Koharu cannot tell which one was used. The key belongs to your account: it is billed to
you, visible in your console, and revocable at any time. Revoking it makes Koharu ask you to
reconnect — there is no automatic refresh, because a PKCE-issued key is durable rather than
refreshable.

Koharu talks to two different OrcaRouter origins, and it never derives one from the other:

| Purpose                | Default                           |
| ---------------------- | --------------------------------- |
| Authorization and key exchange | `https://www.orcarouter.ai` |
| Inference and model discovery  | `https://api.orcarouter.ai/v1` |

Self-hosted deployments can point both at one origin with `ORCA_BASE_URL`, or override them
separately with `ORCA_AUTH_BASE_URL` and `ORCA_API_BASE_URL`. Explicit settings in
**Settings → Providers** take precedence over the environment. Remote origins must use HTTPS;
plain HTTP is accepted only for loopback.

Model lists are filtered per use. The text picker excludes image-generation, rerank and video
models. With **Vision** on, only models that declare image input are offered, and a saved model
that no longer qualifies is cleared instead of being sent. If the live catalog is unreachable,
Koharu shows a small verified fallback list rather than leaving you with no models.

<Steps>
  <Step title='Save the connection'>
    Open **Settings → Providers**, choose a provider, and fill in its fields. Hosted services
    require credentials. A local compatible server needs its base URL; LM Studio defaults to
    `http://localhost:1234` and OpenAI-compatible defaults to `http://localhost:11434/v1`. Whether a
    local server needs a secret depends on that server.
  </Step>
  <Step title='Select a model'>
    Open the processing selector or **Settings → Translation**. Opening the processing selector, or
    the Settings page, refreshes provider discovery. An unreachable provider may have no discovered
    models even while its saved settings remain intact.
  </Step>
  <Step title='Choose whether to include the page image'>
    **Vision** is on by default and the switch stays available for every model. If the selected
    model does not accept images, Koharu drops the image from the request. OpenAI-compatible
    endpoints are assumed to accept images, so turn the switch off when the server cannot handle
    image messages.
  </Step>
  <Step title='Try one page'>
    Check the source OCR, run translation on the current page, and review the response before
    processing a chapter.
  </Step>
</Steps>

## Credentials and privacy

Provider secrets use the operating system's secure credential service. Non-secret endpoint settings live in `~/.koharu/config.toml`.

Local models keep prompts and text on your machine after download. Hosted providers receive request content and apply their own retention terms. Local detection and OCR do not make a hosted translation request local.

<Warning>
  Keep keys out of project instructions, text layers, and configuration files. Save credentials
  through **Settings → Providers**.
</Warning>
