We use [Sentry](https://sentry.io/) to identify errors, diagnose crashes, and improve reliability. This notice covers that diagnostic reporting.

## Diagnostic information

Reports may include error messages, stack traces, relevant logs, software versions, device and operating system information, timestamps, and context around a problem. They may also include IP addresses, URLs, file paths, and diagnostic identifiers.

This information can contain personal data, such as a username in a file path or content included in an error message. Filtering can reduce sensitive information, but reports should not be assumed to be anonymous.

Sentry, provided by Functional Software, Inc., processes reports on our behalf. See Sentry's [data processing terms](https://sentry.io/legal/dpa/) and [subprocessor list](https://sentry.io/legal/subprocessors/) for details about its processing arrangements.

## Questions

If you have questions or concerns about privacy, [open a GitHub issue](https://github.com/koharu-rs/koharu/issues/new/choose). Issues are public: do not include personal information, credentials, or private files. If your concern requires sensitive details, ask how to share them privately first.
