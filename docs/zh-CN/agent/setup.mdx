Koharu 智能体是内置的项目感知 Codex 客户端。它使用 ChatGPT 账号的设备代码认证，不会要求 OpenAI API Key。

## 登录

1. 打开项目并选择右侧的**智能体**面板。
2. 选择**使用 Codex 登录**。
3. Koharu 会在浏览器中打开设备授权页面。
4. 输入显示的设备代码并批准登录。
5. 返回 Koharu，等待账号与模型列表载入。

同一时间只能进行一次登录。重试前请取消现有尝试。

## 配置智能体

在属性中选择 Codex 模型与推理级别。较高推理级别可能更适合长而模糊的项目修改，但耗时更长。智能体配置与翻译服务设置分开保存。

智能体使用当前项目的语义状态作为初始上下文，不会自动上传所有页面。只有它调用视觉页面检查工具时，指定页面才会被渲染并附加。

## 账号边界

智能体认证与**设置 -> 服务商**中的凭据相互独立。登录 ChatGPT 不会把 OpenAI 配置为流水线翻译，保存 OpenAI API Key 也不会登录智能体。

**退出登录**会取消活动任务、清除当前智能体会话，并移除 Koharu 使用的 Codex 账号授权。
