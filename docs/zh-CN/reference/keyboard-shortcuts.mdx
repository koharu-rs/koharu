项目打开且文本输入框未获得焦点时，单键工具快捷键才会生效。

## 工具

| 操作 | 默认键 |
| --- | --- |
| 选择 | `V` |
| 文本 | `T` |
| 绘画 | `B` |
| 橡皮擦 | `E` |
| 取色器 | `I` |
| 移除 | `J` |
| 平移 | `H` |
| 适应窗口 | `0` |

可在**设置 -> 快捷键**中修改。

## 导航与手势

| 操作 | 快捷键 |
| --- | --- |
| 临时平移 | 按住 `Space` 拖动 |
| 取消当前手势或清空选择 | `Escape` |
| 适配当前页面 | 默认为 `0` |

松开 Space 后恢复先前工具。应用失去焦点时，未完成的画布手势会取消。

## 编辑

| 操作 | Windows/Linux | macOS |
| --- | --- | --- |
| 撤销 | `Ctrl+Z` | `Command+Z` |
| 重做 | `Ctrl+Shift+Z` | `Command+Shift+Z` |
| 选择页面全部可编辑图层 | `Ctrl+A` | `Command+A` |
| 删除所选图层 | `Delete` / `Backspace` | `Delete` / `Backspace` |

文本编辑时应用不会拦截这些命令。不要为多个工具分配同一个字符；发生冲突时，工具栏顺序中第一个匹配项会生效。
