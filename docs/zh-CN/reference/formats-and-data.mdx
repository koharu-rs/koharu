## 支持格式

| 用途 | 格式 |
| --- | --- |
| 页面导入 | PNG、JPEG、WebP、CBZ、ZIP、RAR、PDF |
| 合并导出 | PNG |
| 分层交换导出 | PSD |
| Koharu 工作项目 | `.khrproj` 目录 |

PSD 不是 Koharu 项目备份。继续语义编辑需要保留 `.khrproj`。

## 项目

```text
Documents/Koharu/<project-name>.khrproj/
```

目录包含交替使用的持久状态文件与内容寻址 blob 数据。原稿、生成画面和手工栅格都可能由状态引用。项目打开期间不要重命名、删除或编辑内部文件。

从开始页面删除项目会递归移除整个目录，无法撤销。

## 配置与凭据

共享设置位于 `~/.koharu/config.toml`，按流水线、翻译服务、排字和智能体划分所有者区段。缺少区段或新增字段时会合并默认值。错误的手工编辑可能阻止初始化，请优先使用设置 UI。

服务商凭据位于操作系统安全凭据服务，与配置和项目文件分离。备份项目不会备份 API Key 或智能体账号会话。

## 运行时与模型缓存

```text
<OS cache>/koharu/packages/
```

缓存可以重建。关闭 Koharu 后移除它，会迫使应用重新解析所需包与模型。桌面进程或原生库仍在运行时绝不要删除缓存。

完整备份应在关闭项目后复制整个 `.khrproj`。需要非秘密设置时单独备份 `config.toml`，在恢复设备上重新配置凭据。
