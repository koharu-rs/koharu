本教程展示最短的完整桌面流程。请先准备一张清晰的 PNG、JPEG 或 WebP 漫画页面。

## 1. 创建项目

启动 Koharu，在**新建项目**中输入名称并选择**创建**。Koharu 会在 `Documents/Koharu` 下建立自包含的 `.khrproj` 目录，然后打开编辑器。

## 2. 导入页面

选择**文件 -> 导入页面**，或使用页面栏的导入按钮。选择**文件**并指定原稿。图像会复制到项目，因此之后无需把原文件保留在原位置。

## 3. 选择翻译输出

打开画布上方的处理选择器，选择翻译模型、目标语言，以及可选的项目级指令。如果使用托管服务，请先在**设置 -> 服务商**中保存凭据与连接设置。

## 4. 运行流水线

范围保留为**当前页面**，选中全部四个阶段，然后选择**运行**。

1. 检测文字、气泡与分格
2. 对检测区域执行 OCR
3. 翻译识别出的文字
4. 修复原文字样所在的画面

翻译和图像修复都依赖检测，翻译还依赖 OCR。活动中心会显示当前页面、阶段和模型。

## 5. 审校与修正

选择文本图层，在检查器中比较原文与译文。直接修正 OCR 或翻译，不合适的修改可以撤销。

自动清除遗漏文字时使用**移除**工具。确定性的手工修补使用**绘画**或**橡皮擦**，缺少文本框时使用**文本**工具。

## 6. 排字

调整字体、字号、自动适配、对齐、书写方向、填充与描边。Koharu 只渲染译文；OCR 原文保留为可编辑语义数据，但不会作为可见后备文字。

## 7. 导出

选择**文件 -> 导出 PNG**获得合并图像，或选择**导出 PSD**获得分层文档，并指定输出目录。

接下来可了解[批量处理页面](/zh-CN/workflow/process-pages)、[清理与图像修复](/zh-CN/workflow/cleanup-and-inpainting)和[PSD 导出](/zh-CN/workflow/export)。
