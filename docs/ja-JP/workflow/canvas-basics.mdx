Koharu は透明なデスクトップ UI の下にネイティブ描画したページを表示します。ツールバーはポインター操作を、インスペクターは選択レイヤーの永続プロパティを変更します。

## 表示を移動する

- **移動**はプロジェクトのジオメトリを変えずに表示を移動します。
- ステータスバーでズームを変更します。
- **表示 -> ウィンドウに合わせる**または `0` でページをフィットします。
- 別ページを選ぶとフィット表示へ戻ります。

## 選択と変形

**選択**で編集可能レイヤーを選びます。修飾キーで複数選択でき、対応レイヤーは移動、サイズ変更、回転できます。ドラッグ中はプレビューし、完了時にコミットします。キャンセルすると以前の表示へ戻ります。

## テキストを追加する

**テキスト**でクリックするとポイントテキスト、ドラッグすると段落テキストボックスを作成します。翻訳を入力してからフィットと組版を設定します。

## 描画と消去

**描画**は選択色と直径で手動ラスターを描き、**消しゴム**は手動ラスターのピクセルを消します。これらは永続する画像編集で、モデル生成インペイントとは別です。

## 色を取得する

**カラーピッカー**で合成キャンバスの色を取得し、描画やテキストに利用できます。

## 原文文字を除去する

**削除**は手動インペイント用マスクを描きます。このマスクは次回のインペイント処理で消費され、表示レイヤーにはなりません。詳しくは[画像修復とインペイント](/ja-JP/workflow/cleanup-and-inpainting)を参照してください。

単一キーのツールショートカットはテキスト入力中には無効です。
