まず起動画面、アクティビティセンター、ダイアログに表示された完全なエラーを確認します。どの境界が失敗したか分かる前にプロジェクトやキャッシュを削除しないでください。

## 起動が完了しない

ネイティブランタイムの初期化後にプロジェクトブラウザーが操作可能になります。初回は GitHub リリースアセットへ接続できることを確認し、ダウンロード完了を待ちます。

繰り返し失敗する場合は、全 Koharu プロセスを閉じ、GPU ドライバーを更新して再起動し、安定したネットワークで再試行して完全な初期化エラーを保存します。DLL や共有ライブラリがロードされたままランタイムディレクトリを削除しないでください。

## モデル取得が失敗する

対象 Hugging Face リポジトリへの接続と空き容量を確認します。プロキシ、地域制限、認証、ウイルス対策、中断が原因になり得ます。同じモデルを 1 回再試行し、同じファイルで失敗するならリポジトリ、ファイル名、完全なエラーを報告してください。

## CPU へフォールバックする

Apple シリコンでは Metal、その後 CUDA、ROCm/HIP、Vulkan を利用可能な範囲で試します。GPU を検出しても対応ドライバーとランタイムが必要です。リソースモニターと起動ログで実際に選ばれたバックエンドを確認してください。

## 検出・OCR 品質が低い

ページの向きと可読性、検出領域を確認し、しきい値は複数ページで慎重に調整します。日本語原稿ではマンガ向け OCR も試し、翻訳前に原文を手動修正してください。

## インペイントが画像を壊す

小さい手動マスクを使い、吹き出し線や線画を避けます。重い生成モデルの前に直接モデルを試します。手動修正は独立した手動ラスターへ残してください。

## 翻訳プロバイダーが失敗する

**設定 -> プロバイダー**で認証情報、ベース URL、固有項目を確認し、モデル一覧を更新します。OpenAI 互換サーバーではチャットエンドポイントとビジョン対応を実際の仕様に合わせてください。

## Agent がサインイン・実行できない

サインインと Agent 要求はそれぞれ同時に 1 つだけです。既存試行をキャンセルし、意図した ChatGPT アカウントでブラウザー承認が完了したか確認します。Agent 認証と OpenAI プロバイダーキーは別です。

## テキストが表示されない

Koharu は翻訳だけを描画します。翻訳文、表示状態、不透明度、対象文字を収録したフォントを確認し、大きな文章変更後は自動フィットをリセットします。

## 詳細ログ

```bash
# macOS / Linux
RUST_LOG=debug koharu
```

```powershell
# Windows PowerShell
$env:RUST_LOG='debug'
koharu.exe
```
