単一キーのツールショートカットは、プロジェクトが開いていてテキスト入力欄にフォーカスがない場合に動作します。

## ツール

| 操作 | 既定 |
| --- | --- |
| 選択 | `V` |
| テキスト | `T` |
| 描画 | `B` |
| 消しゴム | `E` |
| カラーピッカー | `I` |
| 削除 | `J` |
| 移動 | `H` |
| ウィンドウに合わせる | `0` |

**設定 -> ショートカット**で変更できます。

## 表示とジェスチャー

| 操作 | キー |
| --- | --- |
| 一時的に移動 | `Space` を押しながらドラッグ |
| 現在のジェスチャーをキャンセル、選択解除 | `Escape` |
| 現在ページをフィット | 既定で `0` |

Space を離すと以前のツールへ戻ります。アプリからフォーカスが外れると未完了ジェスチャーはキャンセルされます。

## 編集

| 操作 | Windows/Linux | macOS |
| --- | --- | --- |
| 元に戻す | `Ctrl+Z` | `Command+Z` |
| やり直す | `Ctrl+Shift+Z` | `Command+Shift+Z` |
| ページの編集可能レイヤーを全選択 | `Ctrl+A` | `Command+A` |
| 選択レイヤーを削除 | `Delete` / `Backspace` | `Delete` / `Backspace` |

テキスト入力中はアプリがこれらを横取りしません。同じ文字を複数ツールへ割り当てると、ツールバー順で最初に一致したものが選ばれるため避けてください。
