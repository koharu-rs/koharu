Agent は現在開いているプロジェクトだけを操作します。対象ページやテキストを特定できる具体的な目的と範囲を伝えてください。

## できること

現在のホストツールでは次を実行できます。

- 画像なしで最新の意味プロジェクト状態を調査
- 見た目が必要な特定ページをレンダリングして確認
- ページ名変更、並べ替え、削除
- 段落テキストボックス追加
- 原文、翻訳、組版、ジオメトリ、表示、不透明度の編集
- 要素の移動または削除
- プロジェクト、選択ページ、選択テキストにパイプライン実行

これらのツールでは、新しい原稿ファイルの読込、書き出し、プロバイダー認証情報の管理、開いているプロジェクト外の操作はできません。

## 良い依頼を書く

範囲、結果、制約を明記します。

> 3〜5 ページを確認し、明らかな OCR 誤りを直して、敬称を残した自然な英語へ翻訳してください。組版は変更しないでください。

視覚作業では確認点を指定します。

> 8 ページのテキストが吹き出しからあふれていないか確認し、サイズと改行だけを調整してください。

テキストだけの作業では意味調査の方が軽く、画像送信も避けられます。

## 変更と履歴

Agent 編集はデスクトップ UI と同じプロジェクト操作を使います。成功した変更はシーン、レンダラー、リビジョン、元に戻す履歴へ反映されます。

Agent からのパイプラインも段階的にコミットされ、協調停止に対応します。チャット要求のキャンセルは Agent が開始したパイプラインにも停止を要求します。

完了後は変更ページ、原文と翻訳、ジオメトリと組版を確認し、不要なまとまりは元に戻してから書き出してください。同時に実行できる Agent 要求は 1 つです。
